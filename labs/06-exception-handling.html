Before we start

Why this lab

A customer tries to withdraw 10,000 from an account that holds 5,000. Should the program crash, quietly do nothing, or explain what went wrong?

It should throw an exception that the caller can catch and report. In this lab the bank speaks in exceptions: InvalidAccountException, InsufficientFundsException and TransactionException.

Theory 1 of 5

What is an exception?

  • An exception is an object thrown when something abnormal happens; it interrupts the normal flow.
  • A matching catch handles it; if nobody catches it, the program stops with a stack trace.

What is an exception?

try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Error: " + e.getMessage());
}

Theory 2 of 5

The exception hierarchy

  • Error: serious JVM problems — do not catch.
  • Exception: conditions a program can handle.
  • RuntimeException and its subclasses are unchecked.

Theory 4 of 5

throw, throws and finally

public void deposit(double amount) throws InvalidAccountException {
    if (amount <= 0) {
        throw new InvalidAccountException("Deposit amount must be positive.");
    }
    balance += amount;
}

try { account.deposit(500.0); }
catch (InvalidAccountException e) { System.out.println("Error: " + e.getMessage()); }
finally { System.out.println("Transaction attempt completed."); }
  • throw raises an exception object; throws in the header warns callers.
  • finally runs whether or not an exception happened — use it for cleanup and logging.

Theory 5 of 5

Custom exceptions and wrapping

  • Extend Exception (checked) or RuntimeException (unchecked) and pass the message to super.
  • Wrapping turns a low-level error into one meaningful type; getCause() still returns the original.

Custom exceptions and wrapping

} catch (InsufficientFundsException e) {
    throw new TransactionException("Transfer failed.", e);   // keep the cause
}

Implementation design

Execution flow

  1. Create two valid accounts inside try-catch
  2. Try invalid accounts (empty number, negative balance) and catch the checked exception
  3. Withdraw too much and catch the unchecked exception
  4. Do valid deposits and withdrawals
  5. Show that finally always runs
  6. Transfer successfully, then fail a transfer and read the wrapped cause
  7. Reject negative amounts and print the final balances

Three custom exceptions make each failure self-explaining; transfer() wraps lower-level failures.

public class InvalidAccountException extends Exception {

    public InvalidAccountException(String message) {
        super(message);
    }

    public InvalidAccountException(String message, Throwable cause) {
        super(message, cause);
    }
}
  • Extends Exception, so callers must catch or declare it.
  • The second constructor keeps a cause.

public BankAccount(String accountNumber, String owner, double initialBalance)

        throw new InvalidAccountException("Account number cannot be null or empty.");
    }

        throw new InvalidAccountException("Owner name cannot be null or empty.");
    }
    if (initialBalance < 0.0) {
        throw new InvalidAccountException(

    }

    this.owner = owner;
    this.balance = initialBalance;
    totalAccounts++;
}
  • throw stops construction, so invalid accounts are never counted.
  • throws in the header warns callers.

Code walkthrough 5 of 10 · BankAccount.java

withdraw() can fail in two ways

public void withdraw(double amount) throws InvalidAccountException {
    if (amount <= 0.0) {
        throw new InvalidAccountException(
                "Withdrawal amount must be positive. Provided: " + amount);
    }
    if (amount > balance) {
        throw new InsufficientFundsException(
                "Insufficient funds. Requested: " + amount + ", Available: " + balance);
    }
    balance = balance - amount;
    System.out.println("[" + accountNumber + "] Withdrawal: " + amount
            + " | New balance: " + balance);
}
  • Bad amount → checked exception (declared in throws).
  • Too little money → unchecked exception (no declaration needed).

Code walkthrough 6 of 10 · BankAccount.java

transfer() wraps low-level failures

public void transfer(BankAccount target, double amount) throws TransactionException {
    if (target == null) {
        throw new TransactionException("Transfer failed: target account is null.");
    }
    try {
        System.out.println("--- Starting transfer ---");
        System.out.println("From: " + this.accountNumber + " | To: "
                + target.accountNumber + " | Amount: " + amount);
        this.withdraw(amount);
        target.deposit(amount);
        System.out.println("Transfer completed successfully.");
    } catch (InsufficientFundsException e) {
        throw new TransactionException(
                "Transfer failed: insufficient funds in source account.", e);
    } catch (InvalidAccountException e) {
        throw new TransactionException(
                "Transfer failed: invalid transaction amount.", e);
    }
}
  • Both failures become one TransactionException; e is kept as the cause.

public class InvalidAccountException extends Exception {

    public InvalidAccountException(String message) {
        super(message);
    }

    public InvalidAccountException(String message, Throwable cause) {
        super(message, cause);
    }
}
public class InsufficientFundsException extends RuntimeException {

    public InsufficientFundsException(String message) {
        super(message);
    }

    public InsufficientFundsException(String message, Throwable cause) {
        super(message, cause);
    }
}
public class TransactionException extends Exception {

    public TransactionException(String message) {
        super(message);
    }

    public TransactionException(String message, Throwable cause) {
        super(message, cause);
    }
}
public class BankAccount {

    private String accountNumber;
    private String owner;
    private double balance;

    private static int totalAccounts = 0;

    public BankAccount(String accountNumber, String owner, double initialBalance)
            throws InvalidAccountException {

        if (accountNumber == null || accountNumber.trim().isEmpty()) {
            throw new InvalidAccountException("Account number cannot be null or empty.");
        }
        if (owner == null || owner.trim().isEmpty()) {
            throw new InvalidAccountException("Owner name cannot be null or empty.");
        }
        if (initialBalance < 0.0) {
            throw new InvalidAccountException(
                    "Initial balance cannot be negative. Provided: " + initialBalance);
        }
        this.accountNumber = accountNumber;
        this.owner = owner;
        this.balance = initialBalance;
        totalAccounts++;
    }

    public void deposit(double amount) throws InvalidAccountException {
        if (amount <= 0.0) {
            throw new InvalidAccountException(
                    "Deposit amount must be positive. Provided: " + amount);
        }
        balance = balance + amount;
        System.out.println("[" + accountNumber + "] Deposit: " + amount
                + " | New balance: " + balance);
    }

    public void withdraw(double amount) throws InvalidAccountException {
        if (amount <= 0.0) {
            throw new InvalidAccountException(
                    "Withdrawal amount must be positive. Provided: " + amount);
        }
        if (amount > balance) {
            throw new InsufficientFundsException(
                    "Insufficient funds. Requested: " + amount + ", Available: " + balance);
        }
        balance = balance - amount;
        System.out.println("[" + accountNumber + "] Withdrawal: " + amount
                + " | New balance: " + balance);
    }

    public void transfer(BankAccount target, double amount) throws TransactionException {
        if (target == null) {
            throw new TransactionException("Transfer failed: target account is null.");
        }
        try {
            System.out.println("--- Starting transfer ---");
            System.out.println("From: " + this.accountNumber + " | To: "
                    + target.accountNumber + " | Amount: " + amount);
            this.withdraw(amount);
            target.deposit(amount);
            System.out.println("Transfer completed successfully.");
        } catch (InsufficientFundsException e) {
            throw new TransactionException(
                    "Transfer failed: insufficient funds in source account.", e);
        } catch (InvalidAccountException e) {
            throw new TransactionException(
                    "Transfer failed: invalid transaction amount.", e);
        }
    }

    public String getAccountNumber() { return accountNumber; }
    public String getOwner() { return owner; }
    public double getBalance() { return balance; }
    public static int getTotalAccounts() { return totalAccounts; }

    public void display() {
        System.out.println("Account: " + accountNumber + " | Owner: " + owner
                + " | Balance: " + balance);
    }
}
public class Lab6Demo {

    public static void main(String[] args) {

        // 1. Creating Bank Accounts
        System.out.println("=== Creating Bank Accounts ===");
        BankAccount account1 = null;
        BankAccount account2 = null;
        try {
            account1 = new BankAccount("ACC001", "Alice", 5000.0);
            System.out.println("Account 1 created successfully.");
        } catch (InvalidAccountException e) {
            System.out.println("Error creating account 1: " + e.getMessage());
        }
        try {
            account2 = new BankAccount("ACC002", "Bob", 3000.0);
            System.out.println("Account 2 created successfully.");
        } catch (InvalidAccountException e) {
            System.out.println("Error creating account 2: " + e.getMessage());
        }

        // 2. Invalid Account Creation
        System.out.println("\n=== Invalid Account Creation ===");
        try {
            BankAccount invalidAccount = new BankAccount("", "Charlie", 1000.0);
        } catch (InvalidAccountException e) {
            System.out.println("Caught checked exception: " + e.getMessage());
        }
        try {
            BankAccount invalidAccount = new BankAccount("ACC003", "Diana", -500.0);
        } catch (InvalidAccountException e) {
            System.out.println("Caught checked exception: " + e.getMessage());
        }

        // 3. Insufficient Funds
        System.out.println("\n=== Insufficient Funds Example ===");
        try {
            account1.withdraw(10000.0);
        } catch (InsufficientFundsException e) {
            System.out.println("Caught unchecked exception: " + e.getMessage());
        } catch (InvalidAccountException e) {
            System.out.println("Caught checked exception: " + e.getMessage());
        }

        // 4. Valid Deposit and Withdrawal
        System.out.println("\n=== Valid Transactions ===");
        try {
            account1.display();
            account1.deposit(2000.0);
            account1.withdraw(1500.0);
            account1.display();
        } catch (InvalidAccountException e) {
            System.out.println("Transaction error: " + e.getMessage());
        }

        // 5. try-catch-finally
        System.out.println("\n=== try-catch-finally Example ===");
        try {
            System.out.println("Attempting to withdraw 500 from account1...");
            account1.withdraw(500.0);
            System.out.println("Withdrawal successful.");
        } catch (InsufficientFundsException e) {
            System.out.println("Caught InsufficientFundsException: " + e.getMessage());
        } catch (InvalidAccountException e) {
            System.out.println("Caught InvalidAccountException: " + e.getMessage());
        } finally {
            System.out.println("Finally block: cleanup or logging code runs.");
            account1.display();
        }

        // 6. Successful Transfer
        System.out.println("\n=== Successful Transfer ===");
        try {
            account1.transfer(account2, 1000.0);
        } catch (TransactionException e) {
            System.out.println("Caught TransactionException: " + e.getMessage());
            System.out.println("Cause: " + e.getCause().getMessage());
        }

        // 7. Failed Transfer
        System.out.println("\n=== Failed Transfer ===");
        try {
            account2.transfer(account1, 5000.0);
        } catch (TransactionException e) {
            System.out.println("Caught TransactionException: " + e.getMessage());
            System.out.println("Root cause: " + e.getCause().getMessage());
        }

        // 8. Invalid Transaction Amounts
        System.out.println("\n=== Invalid Transaction Amounts ===");
        try {
            account1.deposit(-100.0);
        } catch (InvalidAccountException e) {
            System.out.println("Caught deposit error: " + e.getMessage());
        }
        try {
            account1.withdraw(-50.0);
        } catch (InsufficientFundsException e) {
            System.out.println("Caught insufficient funds error: " + e.getMessage());
        } catch (InvalidAccountException e) {
            System.out.println("Caught withdrawal error: " + e.getMessage());
        }

        // 9. Final Account States
        System.out.println("\n=== Final Account States ===");
        account1.display();
        account2.display();
        System.out.println("Total accounts created: " + BankAccount.getTotalAccounts());
    }
}

Summary

  • Exceptions interrupt normal flow; catch them to recover with a clear message.
  • Checked exceptions must be caught or declared; unchecked ones need not be.
  • throw raises, throws declares, finally always runs.
  • Custom exceptions name domain errors.
  • Wrap low-level exceptions to give callers one meaningful type, keeping the cause.
