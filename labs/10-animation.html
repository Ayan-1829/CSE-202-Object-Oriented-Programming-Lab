Today’s build

  • Ten files: the abstract GameObject with Player, Bullet, Explosion and the abstract Enemy (Drone, Tank). GamePanel runs the loop, CodeCommando opens the window, Sprites comes from Chapter 9.

What the program does

  1. Open the window and start the GameLoop thread
  2. Each frame: move the player from the keys, fire when Space is held
  3. Spawn a drone or a tank now and then, faster as the score grows
  4. Move every enemy, bullet and explosion
  5. Check bullets against enemies and the player, and enemies against the player
  6. Remove finished objects; GAME OVER at 0 HP; R restarts

Topic 2 of 6 · our game program · 1 of 3 · GamePanel.java

The game loop

// The game loop: update, then repaint, then sleep until the next frame
@Override
public void run() {
    while (running) {
        long begin = System.currentTimeMillis();
        synchronized (lock) {
            update();
        }
        repaint();
        long wait = 16 - (System.currentTimeMillis() - begin);
        try {
            Thread.sleep(Math.max(2, wait));
        } catch (InterruptedException e) {
            return;
        }
    }
}
  • update() runs while holding the lock; repaint() asks the EDT to draw.
  • The sleep time subtracts the time the frame already took.

update(): the player

private void update() {
    if (gameOver) {
        if (restart) {
            restart = false;
            newGame();
        }
        return;
    }
    frame++;

    // 1. the player
    player.move((right ? 1 : 0) - (left ? 1 : 0), (down ? 1 : 0) - (up ? 1 : 0));
    player.update();
    if (firing) {
        Bullet b = player.tryShoot();
        if (b != null) bullets.add(b);
    }
  • After GAME OVER, update() only waits for R.
  • The key flags become a direction and a trigger.

Two threads sharing data

In the game:
Two threads: the loop and the EDT
public void run() {                       // the game thread
    while (running) {
        synchronized (lock) {
            update();                     // changes the lists
        }
        repaint();                        // the EDT will paint
        Thread.sleep(16);
    }
}

protected void paintComponent(Graphics g0) {   // the EDT
    synchronized (lock) {
        // draw every object
    }
}
  • One thread runs the loop; the Swing thread handles keys and painting.
  • A flag one thread writes and another reads should be volatile, so the change is seen at once.
  • In the game: the key flags and the running flag are volatile.
  • The game thread changes the objects; the EDT draws them.
  • Both lock the same object, so painting never sees a half-updated list (Chapter 8).
  • Key flags are volatile: written by the EDT, read by the game thread.

public class GamePanel extends JPanel implements Runnable, KeyListener {
    public static final int W = 760, H = 380, GROUND = 330;

    private final Object lock = new Object();           // guards the lists below
    private final ArrayList<Enemy> enemies = new ArrayList<>();
    private final ArrayList<Bullet> bullets = new ArrayList<>();
    private final ArrayList<Explosion> explosions = new ArrayList<>();
    private final Random random = new Random();
    private Player player;
    private int score, frame, spawnTimer;
    private boolean gameOver;

    private volatile boolean running;
    private Thread gameThread;

        setFocusable(true);
        addKeyListener(this);

    }

@Override
public void keyPressed(KeyEvent e) {

@Override

private void setKey(int code, boolean down) {
    switch (code) {
        case KeyEvent.VK_LEFT:  left = down; break;
        case KeyEvent.VK_RIGHT: right = down; break;
        case KeyEvent.VK_UP:    up = down; break;
        case KeyEvent.VK_DOWN:  this.down = down; break;
        case KeyEvent.VK_SPACE: firing = down; break;
        case KeyEvent.VK_R:     if (down) restart = true; break;
        default: break;
    }
}

@Override
public void keyTyped(KeyEvent e) { }
  • The EDT only sets flags; the game thread reads them every frame.

Topic 4 of 6 · our game program · 1 of 2 · GamePanel.java

update(): bullets hit things

// 4. collisions
for (Bullet b : bullets) {
    if (!b.isActive()) continue;
    if (b.isFromEnemy()) {
        if (b.collidesWith(player)) {
            b.destroy();
            player.takeDamage(20);
        }
        continue;
    }
    for (Enemy e : enemies) {
        if (e.isActive() && b.collidesWith(e)) {
            b.destroy();
            e.takeHit();
            if (!e.isActive()) {
                score += e.getPoints();
                explosions.add(new Explosion(e.x + e.w / 2.0, e.y + e.h / 2.0));
            }
            break;
        }
    }
}
  • Enemy shells hurt the player; player bullets hurt enemies.
  • A destroyed enemy adds points and an explosion.

    // enemies that crash into the player
    for (Enemy e : enemies) {
        if (e.isActive() && e.collidesWith(player)) {

Topic 5 of 6

Double buffering

In the game:
Double buffering and smooth animation
  • Draw the whole frame on a hidden image first, then copy it to the screen in one go.
  • The viewer never sees a half-drawn frame, so nothing flickers.
  • Swing’s JPanel does this for you, so the game does not flicker.
  • Drawing straight onto the screen can flicker: you see half-finished frames.
  • Double buffering draws the whole frame off-screen first, then shows it in one go.
  • Swing’s JPanel is double-buffered by default, so the game does not flicker.
  • javax.swing.Timer is another way to run a loop: it calls your code on the EDT itself.

Topic 5 of 6 · our game program · 1 of 2 · GamePanel.java

Painting

@Override
protected void paintComponent(Graphics g0) {
    super.paintComponent(g0);
    Graphics2D g = (Graphics2D) g0;
    g.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);
    synchronized (lock) {               // never draw while the game thread changes the lists
        Sprites.drawBackground(g, W, H, GROUND);
        for (Enemy e : enemies) e.draw(g);
        for (Bullet b : bullets) b.draw(g);
        if (player.isActive()) player.draw(g);
        for (Explosion x : explosions) x.draw(g);
        drawHud(g);
    }
}
  • Painting holds the same lock as update().

import java.awt.Graphics2D;
import java.awt.Rectangle;

// Everything on screen: it has a box, moves every frame and draws itself
public abstract class GameObject {
    protected double x, y;                  // top-left corner of the box
    protected final int w, h;               // size of the box
    protected boolean active = true;        // false = remove it next frame

    public GameObject(double x, double y, int w, int h) {
        this.x = x;
        this.y = y;
        this.w = w;
        this.h = h;
    }

    public abstract void update();
    public abstract void draw(Graphics2D g);

    public Rectangle getBounds() {
        return new Rectangle((int) x, (int) y, w, h);
    }

    public boolean collidesWith(GameObject other) {
        return getBounds().intersects(other.getBounds());
    }

    public boolean isActive() { return active; }
    public void destroy()     { active = false; }
}

// The game: a thread updates the world about 60 times a second, Swing paints it
public class GamePanel extends JPanel implements Runnable, KeyListener {
    public static final int W = 760, H = 380, GROUND = 330;

    private final Object lock = new Object();           // guards the lists below
    private final ArrayList<Enemy> enemies = new ArrayList<>();
    private final ArrayList<Bullet> bullets = new ArrayList<>();
    private final ArrayList<Explosion> explosions = new ArrayList<>();
    private final Random random = new Random();
    private Player player;
    private int score, frame, spawnTimer;
    private boolean gameOver;

    // Written by the Event Dispatch Thread, read by the game thread
    private volatile boolean left, right, up, down, firing, restart;
    private volatile boolean running;
    private Thread gameThread;

    public GamePanel() {
        setPreferredSize(new Dimension(W, H));
        setFocusable(true);
        addKeyListener(this);
        newGame();
    }

    private void newGame() {
        synchronized (lock) {
            enemies.clear();
            bullets.clear();
            explosions.clear();
            player = new Player(70, GROUND);
            score = 0;
            frame = 0;
            spawnTimer = 0;
            gameOver = false;
        }
    }

    public void start() {
        running = true;
        gameThread = new Thread(this, "GameLoop");
        gameThread.start();
    }

    public void stop() {
        running = false;
    }

    // The game loop: update, then repaint, then sleep until the next frame
    @Override
    public void run() {
        while (running) {
            long begin = System.currentTimeMillis();
            synchronized (lock) {
                update();
            }
            repaint();
            long wait = 16 - (System.currentTimeMillis() - begin);
            try {
                Thread.sleep(Math.max(2, wait));
            } catch (InterruptedException e) {
                return;
            }
        }
    }

    private void update() {
        if (gameOver) {
            if (restart) {
                restart = false;
                newGame();
            }
            return;
        }
        frame++;

        // 1. the player
        player.move((right ? 1 : 0) - (left ? 1 : 0), (down ? 1 : 0) - (up ? 1 : 0));
        player.update();
        if (firing) {
            Bullet b = player.tryShoot();
            if (b != null) bullets.add(b);
        }

        // 2. new enemies, a little faster as the score grows
        spawnTimer--;
        if (spawnTimer <= 0) {
            if (random.nextInt(4) == 0) {
                enemies.add(new Tank(W + 10));
            } else {
                enemies.add(new Drone(W + 10, 90 + random.nextInt(170)));
            }
            spawnTimer = Math.max(30, 80 - score / 200);
        }

        // 3. move everything
        for (Enemy e : enemies) {
            e.update();
            Bullet shell = e.tryShoot();
            if (shell != null) bullets.add(shell);
        }
        for (Bullet b : bullets) b.update();
        for (Explosion x : explosions) x.update();

        // 4. collisions
        for (Bullet b : bullets) {
            if (!b.isActive()) continue;
            if (b.isFromEnemy()) {
                if (b.collidesWith(player)) {
                    b.destroy();
                    player.takeDamage(20);
                }
                continue;
            }
            for (Enemy e : enemies) {
                if (e.isActive() && b.collidesWith(e)) {
                    b.destroy();
                    e.takeHit();
                    if (!e.isActive()) {
                        score += e.getPoints();
                        explosions.add(new Explosion(e.x + e.w / 2.0, e.y + e.h / 2.0));
                    }
                    break;
                }
            }
        }
        // enemies that crash into the player
        for (Enemy e : enemies) {
            if (e.isActive() && e.collidesWith(player)) {
                e.destroy();
                player.takeDamage(e.getTouchDamage());
                explosions.add(new Explosion(e.x + e.w / 2.0, e.y + e.h / 2.0));
            }
        }

        // 5. remove what is finished
        enemies.removeIf(e -> !e.isActive());
        bullets.removeIf(b -> !b.isActive());
        explosions.removeIf(x -> !x.isActive());
        if (!player.isActive()) {
            gameOver = true;
        }
    }

    @Override
    protected void paintComponent(Graphics g0) {
        super.paintComponent(g0);
        Graphics2D g = (Graphics2D) g0;
        g.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);
        synchronized (lock) {               // never draw while the game thread changes the lists
            Sprites.drawBackground(g, W, H, GROUND);
            for (Enemy e : enemies) e.draw(g);
            for (Bullet b : bullets) b.draw(g);
            if (player.isActive()) player.draw(g);
            for (Explosion x : explosions) x.draw(g);
            drawHud(g);
        }
    }

    private void drawHud(Graphics2D g) {
        g.setColor(new Color(0, 0, 0, 120));
        g.fillRect(10, 10, 210, 22);
        g.setColor(new Color(220, 60, 60));
        g.fillRect(10, 10, player.getHealth() * 2, 22);
        g.setColor(Color.WHITE);
        g.setFont(new Font("SansSerif", Font.BOLD, 16));
        g.drawString("HP " + player.getHealth(), 16, 27);
        g.drawString("Score " + score, W - 130, 27);
        if (gameOver) {
            g.setFont(new Font("SansSerif", Font.BOLD, 40));
            g.drawString("GAME OVER", W / 2 - 120, H / 2 - 10);
            g.setFont(new Font("SansSerif", Font.PLAIN, 18));
            g.drawString("Score " + score + "  -  press R to play again", W / 2 - 150, H / 2 + 24);
        }
    }

    @Override
    public void keyPressed(KeyEvent e) {
        setKey(e.getKeyCode(), true);
    }

    @Override
    public void keyReleased(KeyEvent e) {
        setKey(e.getKeyCode(), false);
    }

    private void setKey(int code, boolean down) {
        switch (code) {
            case KeyEvent.VK_LEFT:  left = down; break;
            case KeyEvent.VK_RIGHT: right = down; break;
            case KeyEvent.VK_UP:    up = down; break;
            case KeyEvent.VK_DOWN:  this.down = down; break;
            case KeyEvent.VK_SPACE: firing = down; break;
            case KeyEvent.VK_R:     if (down) restart = true; break;
            default: break;
        }
    }

    @Override
    public void keyTyped(KeyEvent e) { }
}

The official lab program

The graded in-lab tasks and report exercises build on this program, not on the game. Read it and run it before you start them.

  1. main creates AnimationApp on the EDT
  2. AnimationApp builds the panel and buttons and starts a daemon AnimationThread
  3. The thread loops: updateAnimation(), repaint(), sleep the rest of the 16 ms frame
  4. updateAnimation moves balls only while running and handles collisions
  5. Start / Pause flip the running flag; Reset restores the three balls
  6. Closing the window ends the program (the thread is a daemon)

Ball = model, AnimationPanel = rendering + state, AnimationThread = loop, AnimationApp = controls.

import java.awt.BasicStroke;
import java.awt.Color;
import java.awt.Graphics2D;

public class Ball {

    private double x;
    private double y;
    private double vx;
    private double vy;
    private int radius;
    private Color colour;

    public Ball(double x, double y, double vx, double vy, int radius, Color colour) {
        this.x = x;
        this.y = y;
        this.vx = vx;
        this.vy = vy;
        this.radius = (radius > 0) ? radius : 15;
        this.colour = colour;
    }

    public void update(int panelWidth, int panelHeight) {
        x = x + vx;
        y = y + vy;
        if (x - radius < 0 || x + radius > panelWidth) {
            vx = -vx;
            x = Math.max(radius, Math.min(panelWidth - radius, x));
        }
        if (y - radius < 0 || y + radius > panelHeight) {
            vy = -vy;
            y = Math.max(radius, Math.min(panelHeight - radius, y));
        }
    }

    public void draw(Graphics2D g) {
        int diameter = 2 * radius;
        g.setColor(colour);
        g.fillOval((int) (x - radius), (int) (y - radius), diameter, diameter);
        g.setColor(Color.BLACK);
        g.setStroke(new BasicStroke(2));
        g.drawOval((int) (x - radius), (int) (y - radius), diameter, diameter);
    }

    public boolean collidesWith(Ball other) {
        double dx = this.x - other.x;
        double dy = this.y - other.y;
        double distance = Math.sqrt(dx * dx + dy * dy);
        return distance <= this.radius + other.radius;
    }

    public void bounceOff(Ball other) {
        double tempVx = this.vx;
        double tempVy = this.vy;
        this.vx = other.vx;
        this.vy = other.vy;
        other.vx = tempVx;
        other.vy = tempVy;
    }

    public double getX() { return x; }
    public double getY() { return y; }
    public int getRadius() { return radius; }
}
import javax.swing.JPanel;
import java.awt.*;
import java.awt.image.BufferedImage;
import java.util.ArrayList;

public class AnimationPanel extends JPanel {

    private ArrayList<Ball> balls;
    private boolean running;

    public AnimationPanel() {
        balls = new ArrayList<Ball>();
        running = false;
        initializeBalls();
        setBackground(Color.WHITE);
    }

    private void initializeBalls() {
        balls.clear();
        balls.add(new Ball(100, 100, 3.0, 2.0, 15, Color.RED));
        balls.add(new Ball(300, 150, -2.5, 3.5, 15, Color.BLUE));
        balls.add(new Ball(200, 300, 2.0, -2.0, 15, Color.GREEN));
    }

    @Override
    protected void paintComponent(Graphics g) {
        super.paintComponent(g);
        if (getWidth() <= 0 || getHeight() <= 0) {
            return;
        }
        BufferedImage buffer = new BufferedImage(getWidth(), getHeight(),
                BufferedImage.TYPE_INT_RGB);
        Graphics2D g2d = buffer.createGraphics();
        g2d.setRenderingHint(RenderingHints.KEY_ANTIALIASING,
                RenderingHints.VALUE_ANTIALIAS_ON);
        g2d.setColor(Color.WHITE);
        g2d.fillRect(0, 0, getWidth(), getHeight());
        drawGrid(g2d);

        synchronized (this) {
            for (Ball ball : balls) {
                ball.draw(g2d);
            }
            g2d.setColor(Color.BLACK);
            g2d.drawString("Balls: " + balls.size() + " | "
                    + (running ? "Running" : "Paused"), 10, getHeight() - 10);
        }
        g.drawImage(buffer, 0, 0, null);
        g2d.dispose();
    }

    private void drawGrid(Graphics2D g2d) {
        g2d.setColor(new Color(220, 220, 220));
        for (int x = 0; x < getWidth(); x += 50) {
            g2d.drawLine(x, 0, x, getHeight());
        }
        for (int y = 0; y < getHeight(); y += 50) {
            g2d.drawLine(0, y, getWidth(), y);
        }
    }

    public synchronized void updateAnimation() {
        if (!running) {
            return;
        }
        int width = getWidth();
        int height = getHeight();
        if (width <= 0 || height <= 0) {
            return;
        }
        for (Ball ball : balls) {
            ball.update(width, height);
        }
        for (int i = 0; i < balls.size(); i++) {
            for (int j = i + 1; j < balls.size(); j++) {
                Ball first = balls.get(i);
                Ball second = balls.get(j);
                if (first.collidesWith(second)) {
                    first.bounceOff(second);
                }
            }
        }
    }

    public synchronized void startAnimation() { running = true; }

    public synchronized void pauseAnimation() { running = false; }

    public synchronized void resetAnimation() {
        running = false;
        initializeBalls();
        repaint();
    }

    public synchronized boolean isRunning() { return running; }

    public synchronized int getBallCount() { return balls.size(); }
}
public class AnimationThread implements Runnable {

    private AnimationPanel panel;

    private static final int TARGET_FPS = 60;
    private static final long FRAME_TIME_MS = 1000 / TARGET_FPS;

    public AnimationThread(AnimationPanel panel) {
        this.panel = panel;
    }

    @Override
    public void run() {
        while (true) {
            long frameStartTime = System.currentTimeMillis();

            panel.updateAnimation();
            panel.repaint();

            long elapsedTime = System.currentTimeMillis() - frameStartTime;
            long sleepTime = FRAME_TIME_MS - elapsedTime;
            if (sleepTime > 0) {
                try {
                    Thread.sleep(sleepTime);
                } catch (InterruptedException e) {
                    System.out.println("Animation thread interrupted.");
                    Thread.currentThread().interrupt();
                    break;
                }
            }
        }
    }
}

Viva questions (1 of 2)

Why does the game loop run on its own thread instead of on the EDT?
Show the answer
A loop with sleep() on the EDT would freeze the window: it could not handle keys or paint while it sleeps.
What would go wrong without synchronized (lock) in paintComponent?
Show the answer
The EDT could draw while the game thread is removing objects from a list, giving a ConcurrentModificationException or a half-updated frame.

Viva questions (2 of 2)

Why are the key flags volatile?
Show the answer
They are written on the EDT and read on the game thread; volatile makes every write visible to the other thread at once.
How does the game decide that a bullet hit a drone?
Show the answer
It checks whether their bounding rectangles overlap with Rectangle.intersects.
