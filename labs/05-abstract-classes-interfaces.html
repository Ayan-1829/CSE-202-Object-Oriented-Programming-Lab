Mission 5 · Rules every object follows

Your mission

Someone asks: “Can I see a game object?” You point at a drone. “No, a plain game object.” There isn’t one — and that is the point.

“Game object” is only an idea, so make GameObject abstract: nobody can create one, and every real object must fill in update() and symbol(). Interfaces add abilities across the family tree, such as being Damageable.

Topic 1 of 5

Abstract classes

In the game:
An abstract GameObject
  • An abstract class is an idea, not a finished thing: you cannot new it.
  • It can hold fields, constructors and normal methods for its subclasses.
  • In the game there is no plain “GameObject”, only players, drones, bullets, …

GameObject: abstract and concrete methods

public abstract class GameObject {
    protected String name;
    protected int x;                        // column on the map, 0..19

    public GameObject(String name, int x) {
        this.name = name;
        this.x = x;
    }

    // Abstract: every kind of object must say how it moves and how it looks
    public abstract void update();
    public abstract char symbol();

    // Concrete: shared by every subclass
    public String getName() { return name; }
    public int getX()       { return x; }

    public String position() {
        return name + " at x=" + x;
    }
}
  • Two abstract methods, three concrete ones.
  • The constructor runs when a subclass calls super(…).

Topic 2 of 5

Abstract methods

In the game:
Abstract methods in code
public abstract class GameObject {
    protected String name;
    protected int x;

    public abstract void update();      // no body: subclasses decide
    public abstract char symbol();

    public String position() {          // a normal, shared method
        return name + " at x=" + x;
    }
}

public class Bullet extends GameObject {
    @Override public void update() { x += 3 * direction; }
    @Override public char symbol() { return direction > 0 ? '>' : '<'; }
}
  • An abstract method has no body, only a heading ending in ;.
  • Every concrete subclass must override it, or be abstract itself.
  • The parent can still call it: each subclass fills it in its own way.
  • An abstract method ends with ; instead of a body.

// Draws a one-line map, 20 cells wide, from any GameObjects
static void drawMap(String label, GameObject[] objects) {
    char[] row = "....................".toCharArray();
    for (GameObject o : objects) {
        if (o.getX() >= 0 && o.getX() < row.length) {
            row[o.getX()] = o.symbol();

    }
    System.out.println(label + "  |" + new String(row) + "|");
}

Topic 4 of 5

Inside an interface

public interface Shooter {
    int RANGE = 8;                // public static final: a constant
    Bullet shoot();               // public and abstract
}

public interface Collectible {
    void collectBy(Player p);

    default String pickupMessage() {   // has a body
        return "picked up";
    }
}
  • Methods are public abstract unless marked otherwise.
  • Fields are public static final: constants.
  • A default method has a body that implementing classes get for free.
  • Interface fields are constants: Shooter.RANGE.

Topic 5 of 5

Abstract class or interface?

Abstract classInterface
A class can…extend oneimplement many
Fieldsany fieldsconstants only
Constructorsyesno
Methodsabstract and normalabstract, default and static
In the gameGameObject: what every object isDamageable, Shooter, Collectible: what it can do
  • Abstract class: shared code and state for close relatives (“is a”). A class extends only one.
  • Interface: an ability unrelated classes can share (“can do”). A class implements many.
  • Often both: class Drone extends GameObject implements Damageable, Shooter.
  • Use an abstract class for a shared base with shared code.

public abstract class Animal {

    protected String name;
    protected int age;

    protected Animal(String name, int age) {
        this.name = name;
        if (age >= 0) {
            this.age = age;
        } else {
            this.age = 0;
        }
    }

    public abstract void makeSound();

    public abstract void eat();

    public String getName() { return name; }
    public int getAge() { return age; }

    public void displayInfo() {
        System.out.println("Name: " + name + ", Age: " + age + " years");
    }
}
public interface Drawable {
    void draw();
    void hide();
}
public interface Eatable {
    boolean isPoisonous();
    int getNutrition();
}
public class Dog extends Animal implements Drawable {

    private String breed;

    public Dog(String name, int age, String breed) {
        super(name, age);
        this.breed = breed;
    }

    @Override
    public void makeSound() {
        System.out.println(name + " barks: Woof! Woof!");
    }

    @Override
    public void eat() {
        System.out.println(name + " is eating dog food from a bowl.");
    }

    @Override
    public void draw() {
        System.out.println("[Drawing] " + name + " (" + breed + ") as a dog.");
    }

    @Override
    public void hide() {
        System.out.println("[Hiding] " + name + " is no longer visible.");
    }

    public String getBreed() { return breed; }
}
public class Bird extends Animal implements Drawable {

    private double wingSpan;

    public Bird(String name, int age, double wingSpan) {
        super(name, age);
        if (wingSpan > 0.0) {
            this.wingSpan = wingSpan;
        } else {
            this.wingSpan = 0.1;
        }
    }

    @Override
    public void makeSound() {
        System.out.println(name + " chirps: Tweet! Tweet!");
    }

    @Override
    public void eat() {
        System.out.println(name + " is pecking at seeds and insects.");
    }

    @Override
    public void draw() {
        System.out.println("[Drawing] " + name + " with wingspan " + wingSpan + "m as a bird.");
    }

    @Override
    public void hide() {
        System.out.println("[Hiding] " + name + " flies away and disappears.");
    }

    public double getWingSpan() { return wingSpan; }
}
public class Fish extends Animal implements Eatable {

    @Override
    public boolean isPoisonous() {
        return false;
    }

    @Override
    public int getNutrition() {
        return 65;

}
public class Lab5Demo {

    static void demonstratePolymorphism(Animal animal) {
        animal.displayInfo();
        animal.makeSound();
        animal.eat();
    }

    static void demonstrateDrawable(Drawable drawable) {
        drawable.draw();
        drawable.hide();
    }

    static void demonstrateEatable(Eatable eatable) {
        System.out.println("Poisonous : " + eatable.isPoisonous());
        System.out.println("Nutrition : " + eatable.getNutrition());
    }

    public static void main(String[] args) {

        // 1. Object Creation
        System.out.println("=== Object Creation ===");
        Dog dog = new Dog("Rex", 5, "Golden Retriever");
        Bird bird = new Bird("Tweety", 2, 0.5);
        Fish fish = new Fish("Nemo", 1, 20);
        System.out.println("Created Dog : " + dog.getName());
        System.out.println("Created Bird: " + bird.getName());
        System.out.println("Created Fish: " + fish.getName());

        // 2. Polymorphism through Animal References
        System.out.println("\n=== Polymorphism through Animal References ===");
        Animal[] animals = {dog, bird, fish};
        for (Animal animal : animals) {
            System.out.println("-------------------------------");
            demonstratePolymorphism(animal);
        }

        // 3. Drawable Interface
        System.out.println("\n=== Drawable Interface ===");
        Drawable[] drawables = {dog, bird};
        for (Drawable drawable : drawables) {
            System.out.println("-------------------------------");
            demonstrateDrawable(drawable);
        }

        // 4. Eatable Interface
        System.out.println("\n=== Eatable Interface ===");
        demonstrateEatable(fish);

        // 5. Abstract Class Instantiation Rule
        System.out.println("\n=== Abstract Class Instantiation Rule ===");
        System.out.println("Animal cannot be instantiated directly.");
        System.out.println("Use concrete subclasses such as Dog, Bird, and Fish.");

        // 6. instanceof with Interfaces
        System.out.println("\n=== instanceof with Interfaces ===");
        System.out.println("dog instanceof Drawable  : " + (dog instanceof Drawable));
        System.out.println("dog instanceof Eatable   : " + (dog instanceof Eatable));
        System.out.println("fish instanceof Drawable : " + (fish instanceof Drawable));
        System.out.println("fish instanceof Eatable  : " + (fish instanceof Eatable));

        // 7. Safe Casting
        System.out.println("\n=== Safe Casting ===");
        Animal animalRef = dog;
        if (animalRef instanceof Dog) {
            Dog castedDog = (Dog) animalRef;
            System.out.println("Casted Dog breed: " + castedDog.getBreed());
        }
    }
}

Summary

  • abstract classes give a shared base and force subclasses to fill in the gaps.
  • An abstract class cannot be created with new.
  • Interfaces describe abilities; a class can implement many.
  • Interface fields are constants; default methods have bodies.
  • Both abstract classes and interfaces work as reference types for polymorphism.
