Topic 1 of 6

What is a thread?

In the game:
Three jobs, three threads
  • A thread is one path of execution: one list of steps being run.
  • A program starts with one thread, main.
  • More threads let several jobs run at the same time.

Topic 2 of 6

Process and thread

  • A process is a running program with its own memory (a browser, a music player).
  • A process holds one or more threads that share its memory.
  • Threads are cheaper to make than processes, but must share carefully.

Topic 3 of 6

Creating a thread

In the game:
Two ways to create a thread
// 1. extend Thread
public class EnemySpawner extends Thread {
    @Override public void run() { … }
}
new EnemySpawner(3).start();

// 2. implement Runnable and hand it to a Thread
public class AmmoRegen implements Runnable {
    @Override public void run() { … }
}
new Thread(new AmmoRegen(10), "AmmoRegen").start();

// 3. a lambda is a short Runnable
new Thread(() -> System.out.println("[Timer] GO!"), "Timer").start();
  • Way 1: extend Thread and override run().
  • Way 2: implement Runnable and pass it to new Thread(…).
  • Way 2 leaves your class free to extend something else.
  • Extending Thread uses up the one superclass a class can have.

Topic 3 of 6 · our game program · 1 of 4 · EnemySpawner.java

EnemySpawner: extending Thread

// Way 1: extend Thread and override run()
public class EnemySpawner extends Thread {
    private final int count;

    public EnemySpawner(int count) {
        super("Spawner");                   // the thread's name
        this.count = count;
    }

    @Override
    public void run() {
        String me = Thread.currentThread().getName();
        for (int i = 1; i <= count; i++) {
            System.out.println("[" + me + "] spawned Drone-" + i);
            try {
                Thread.sleep(300);          // TIMED_WAITING while asleep
            } catch (InterruptedException e) {
                System.out.println("[" + me + "] interrupted, stopping");
                return;
            }
        }
        System.out.println("[" + me + "] wave complete");
    }
}
  • The constructor names the thread with super("Spawner").
  • run() spawns, prints and sleeps 300 ms each time.
  • Interruption ends it early.

AmmoRegen: implementing Runnable

// Way 2: implement Runnable and hand the task to a Thread
public class AmmoRegen implements Runnable {
    private int ammo;

    public AmmoRegen(int ammo) {
        this.ammo = ammo;
    }
  • A plain class: the Thread that runs it is made in main.
  • It keeps the superclass free: it could still extend something else.

Topic 4 of 6

start() or run()?

spawner.start();   // a NEW thread runs run()

direct.run();      // no new thread: main runs it like any method
                   // prints [main] spawned Drone-1
  • start() creates a new thread, which then calls run().
  • Calling run() yourself is a normal method call on the same thread.
  • A thread can be started only once.
  • start() asks the JVM for a new thread, which then calls run().

  • The object stays NEW: it was never started.

Topic 5 of 6

Thread states

  • NEW: created, not started. RUNNABLE: running or ready to run.
  • TIMED_WAITING / WAITING / BLOCKED: paused for a reason.
  • TERMINATED: run() has finished.

Topic 6 of 6

sleep() and join()

Thread.sleep(300);        // pause this thread for 300 ms
                          // throws InterruptedException (checked)

spawner.join();           // main waits here until the spawner ends
regenThread.join();
timer.join();
System.out.println(spawner.getState());   // TERMINATED
  • Thread.sleep(ms) pauses the current thread.
  • t.join() makes the current thread wait until t finishes.
  • Both can throw the checked InterruptedException.
  • sleep() gives other threads a turn and slows a job down.

Starting and joining

regenThread.start();
timer.start();
Thread.sleep(100);
System.out.println("[main] spawner state while sleeping: " + spawner.getState());

// join(): main waits here until each thread has finished
spawner.join();

timer.join();

  • After start(), all three run at once.
  • main sleeps 100 ms and peeks: the spawner is sleeping too.
  • join() waits; then the states are TERMINATED.

public class ThreadDemo {
    public static void main(String[] args) throws InterruptedException {

        System.out.println("=== Creating three game threads ===");
        EnemySpawner spawner = new EnemySpawner(3);
        AmmoRegen regen = new AmmoRegen(10);
        Thread regenThread = new Thread(regen, "AmmoRegen");

        // Way 3: a lambda is a short Runnable
        Thread timer = new Thread(() -> {
            for (int s = 3; s >= 1; s--) {
                System.out.println("[Timer] " + s + "...");
                try {
                    Thread.sleep(400);
                } catch (InterruptedException e) {
                    return;
                }
            }
            System.out.println("[Timer] GO!");
        }, "Timer");

        System.out.println("spawner state before start(): " + spawner.getState());

        System.out.println("\n=== start(): all three run at the same time ===");
        spawner.start();
        regenThread.start();
        timer.start();
        Thread.sleep(100);
        System.out.println("[main] spawner state while sleeping: " + spawner.getState());

        // join(): main waits here until each thread has finished
        spawner.join();
        regenThread.join();
        timer.join();
        System.out.println("[main] all threads finished");
        System.out.println("spawner state after join(): " + spawner.getState());
        System.out.println("ammo after regen: " + regen.getAmmo());

        System.out.println("\n=== run() is just a method call ===");
        EnemySpawner direct = new EnemySpawner(1);
        direct.run();                       // no new thread: runs inside main
        System.out.println("direct state: " + direct.getState() + " (it never started)");
    }
}

public class Counter {

    private int value;
    private String name;

    public Counter(String name, int initialValue) {
        this.name = name;
        this.value = initialValue;
    }

    public synchronized void increment() {
        value++;
        System.out.println(Thread.currentThread().getName()
                + " incremented " + name + " to " + value);
    }

    public synchronized void decrement() {
        value--;
        System.out.println(Thread.currentThread().getName()
                + " decremented " + name + " to " + value);
    }

    public synchronized int getValue() {
        return value;
    }

    public void display() {
        System.out.println(name + " = " + getValue());
    }
}
public class IncrementThread extends Thread {

    private Counter counter;
    private int iterations;

    public IncrementThread(String name, Counter counter, int iterations) {
        super(name);
        this.counter = counter;
        this.iterations = iterations;
    }

    @Override
    public void run() {
        for (int i = 0; i < iterations; i++) {
            counter.increment();
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                System.out.println(getName() + " was interrupted.");
                Thread.currentThread().interrupt();
                break;
            }
        }
        System.out.println(getName() + " finished.");
    }
}
public class DecrementRunnable implements Runnable {

    private Counter counter;
    private int iterations;

    public DecrementRunnable(Counter counter, int iterations) {
        this.counter = counter;
        this.iterations = iterations;
    }

    @Override
    public void run() {
        for (int i = 0; i < iterations; i++) {
            counter.decrement();
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                System.out.println(Thread.currentThread().getName() + " was interrupted.");
                Thread.currentThread().interrupt();
                break;
            }
        }
        System.out.println(Thread.currentThread().getName() + " finished.");
    }
}
public class Lab7Demo {

    public static void main(String[] args) {

        // 1. Shared Counter Creation
        System.out.println("=== Thread Creation and Lifecycle Demo ===");
        Counter counter = new Counter("SharedCounter", 0);
        System.out.println("Initial counter state:");
        counter.display();

        // 2. Creating Threads
        System.out.println("\n=== Creating Threads ===");
        IncrementThread incrementThread = new IncrementThread("IncrementThread-1", counter, 3);
        DecrementRunnable decrementTask1 = new DecrementRunnable(counter, 3);
        DecrementRunnable decrementTask2 = new DecrementRunnable(counter, 2);
        Thread decrementThread1 = new Thread(decrementTask1, "DecrementThread-1");
        Thread decrementThread2 = new Thread(decrementTask2, "DecrementThread-2");

        System.out.println("IncrementThread-1 state: " + incrementThread.getState());
        System.out.println("DecrementThread-1 state: " + decrementThread1.getState());
        System.out.println("DecrementThread-2 state: " + decrementThread2.getState());

        // 3. Starting Threads
        System.out.println("\n=== Starting Threads ===");
        incrementThread.start();
        decrementThread1.start();
        decrementThread2.start();
        System.out.println("All threads started.");
        System.out.println("IncrementThread-1 state after start: " + incrementThread.getState());
        System.out.println("DecrementThread-1 state after start: " + decrementThread1.getState());
        System.out.println("DecrementThread-2 state after start: " + decrementThread2.getState());

        // 4. Waiting for Threads using join()
        System.out.println("\n=== Waiting for Threads to Complete ===");
        try {
            incrementThread.join();
            System.out.println("IncrementThread-1 has terminated.");
            decrementThread1.join();
            System.out.println("DecrementThread-1 has terminated.");
            decrementThread2.join();
            System.out.println("DecrementThread-2 has terminated.");
        } catch (InterruptedException e) {
            System.out.println("Main thread was interrupted.");
            Thread.currentThread().interrupt();
        }

        // 5. Final State
        System.out.println("\n=== Final State ===");
        counter.display();
        System.out.println("IncrementThread-1 final state: " + incrementThread.getState());
        System.out.println("DecrementThread-1 final state: " + decrementThread1.getState());
        System.out.println("DecrementThread-2 final state: " + decrementThread2.getState());
        System.out.println("All threads have completed.");
        System.out.println("Main thread exiting.");
    }
}

What is the difference between spawner.start() and spawner.run()?
Show the answer
start() creates a new thread that then calls run(). run() alone is an ordinary method call on the current thread.
Why is implementing Runnable often better than extending Thread?
