Before we start

Why this lab

Every desktop app is a window full of boxes that react to clicks. How does Java put a button on screen and know when it is pressed?

Swing gives you components (JFrame, JButton…), layout managers to arrange them and listeners that run your code on each click. You will build a small paint program.

Theory 1 of 6

AWT, Swing and applets

  • AWT is the original toolkit using native OS components; Swing is built on it with lightweight, platform-independent components whose names start with J.
  • Applets ran inside browsers; browsers no longer support them, so this lab uses a JFrame desktop app — the drawing and event ideas are the same.

Theory 2 of 6

Components and containers

  • A container holds components: the JFrame holds panels, panels hold buttons, labels and the drawing canvas.

Theory 3 of 6

Layout managers

  • BorderLayout: NORTH, SOUTH, EAST, WEST, CENTER. FlowLayout: left to right. GridLayout: equal cells in rows and columns.

Theory 5 of 6

Custom drawing and repaint()

@Override
protected void paintComponent(Graphics g) {
    super.paintComponent(g);     // clear the background first
    for (Shape shape : shapes) {
        shape.draw(g);           // polymorphic draw
    }
}
  • Graphics offers drawLine, drawRect, fillRect, drawOval, fillOval, drawString.
  • Change the data, then call repaint(); Swing calls paintComponent for you. Never call it yourself.

Theory 6 of 6

The Event Dispatch Thread

SwingUtilities.invokeLater(new Runnable() {
    @Override
    public void run() { new DrawingApp(); }
});
  • Swing is not thread-safe: create and update components only on the EDT.

Implementation design

Program design

Implementation design

Execution flow

  1. main schedules GUI creation on the EDT
  2. DrawingApp builds the window: title (NORTH), canvas (CENTER), controls and status (SOUTH)
  3. Listeners are registered on the three buttons
  4. Add Rectangle / Add Circle: set colour, add a shape, repaint, update status
  5. Clear All: empty the list and repaint
  6. Closing the window ends the program

Layout (DrawingApp), drawing (DrawingPanel) and shape behaviour (Shape subclasses) are separate, so adding a TriangleShape is easy.

private void drawGrid(Graphics g) {
    g.setColor(new Color(220, 220, 220));
    for (int x = 0; x < getWidth(); x += 50) {
        g.drawLine(x, 0, x, getHeight());
    }
    for (int y = 0; y < getHeight(); y += 50) {
        g.drawLine(0, y, getWidth(), y);
    }
}
  • Clear, draw the grid, then call draw(g) on every shape (polymorphism).

import java.awt.Color;
import java.awt.Graphics;

public abstract class Shape {

    protected int x;
    protected int y;
    protected Color colour;

    public Shape(int x, int y, Color colour) {
        this.x = x;
        this.y = y;
        this.colour = colour;
    }

    public abstract void draw(Graphics g);
}
import java.awt.Color;
import java.awt.Graphics;

public class RectangleShape extends Shape {

    private int width;
    private int height;

    public RectangleShape(int x, int y, int width, int height, Color colour) {
        super(x, y, colour);
        this.width = (width > 0) ? width : 100;
        this.height = (height > 0) ? height : 80;
    }

    @Override
    public void draw(Graphics g) {
        g.setColor(colour);
        g.fillRect(x, y, width, height);
        g.setColor(Color.BLACK);
        g.drawRect(x, y, width, height);
    }
}
import java.awt.Color;
import java.awt.Graphics;

public class CircleShape extends Shape {

    private int radius;

    public CircleShape(int x, int y, int radius, Color colour) {
        super(x, y, colour);
        this.radius = (radius > 0) ? radius : 50;
    }

    @Override
    public void draw(Graphics g) {
        int diameter = 2 * radius;
        g.setColor(colour);
        g.fillOval(x - radius, y - radius, diameter, diameter);
        g.setColor(Color.BLACK);
        g.drawOval(x - radius, y - radius, diameter, diameter);
    }
}
import javax.swing.JPanel;
import java.awt.Color;
import java.awt.Graphics;
import java.util.ArrayList;

public class DrawingPanel extends JPanel {

    private ArrayList<Shape> shapes;
    private Color currentColor;

    public DrawingPanel() {
        shapes = new ArrayList<Shape>();
        currentColor = Color.BLUE;
        setBackground(Color.WHITE);
    }

    @Override
    protected void paintComponent(Graphics g) {
        super.paintComponent(g);
        drawGrid(g);
        for (Shape shape : shapes) {
            shape.draw(g);
        }
    }

    private void drawGrid(Graphics g) {
        g.setColor(new Color(220, 220, 220));
        for (int x = 0; x < getWidth(); x += 50) {
            g.drawLine(x, 0, x, getHeight());
        }
        for (int y = 0; y < getHeight(); y += 50) {
            g.drawLine(0, y, getWidth(), y);
        }
    }

    public void addRectangle(int x, int y, int width, int height) {
        shapes.add(new RectangleShape(x, y, width, height, currentColor));
        repaint();
    }

    public void addCircle(int x, int y, int radius) {
        shapes.add(new CircleShape(x, y, radius, currentColor));
        repaint();
    }

    public void clear() {
        shapes.clear();
        repaint();
    }

    public void setCurrentColor(Color colour) {
        this.currentColor = colour;
    }

    public int getShapeCount() {
        return shapes.size();
    }
}
import javax.swing.*;
import java.awt.*;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

public class DrawingApp extends JFrame {

    private DrawingPanel drawingPanel;
    private JLabel statusLabel;
    private JButton rectangleButton;
    private JButton circleButton;
    private JButton clearButton;
    private JComboBox<String> colorComboBox;

    public DrawingApp() {
        setTitle("Drawing Application");
        setSize(800, 600);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLocationRelativeTo(null);
        setupUI();
        addActionListeners();
        setVisible(true);
    }

    private void setupUI() {
        JPanel mainPanel = new JPanel(new BorderLayout(10, 10));
        mainPanel.setBorder(BorderFactory.createEmptyBorder(10, 10, 10, 10));

        JPanel topPanel = new JPanel(new FlowLayout(FlowLayout.LEFT));
        JLabel titleLabel = new JLabel("Drawing Application");
        titleLabel.setFont(new Font("Arial", Font.BOLD, 16));
        topPanel.add(titleLabel);

        drawingPanel = new DrawingPanel();
        drawingPanel.setBorder(BorderFactory.createLineBorder(Color.BLACK, 2));

        JPanel controlPanel = new JPanel(new BorderLayout());
        JPanel buttonPanel = new JPanel(new FlowLayout(FlowLayout.LEFT));
        JLabel colorLabel = new JLabel("Colour:");
        colorComboBox = new JComboBox<String>(
                new String[] {"Blue", "Red", "Green", "Yellow", "Orange", "Purple"});
        rectangleButton = new JButton("Add Rectangle");
        circleButton = new JButton("Add Circle");
        clearButton = new JButton("Clear All");

        buttonPanel.add(colorLabel);
        buttonPanel.add(colorComboBox);
        buttonPanel.add(rectangleButton);
        buttonPanel.add(circleButton);
        buttonPanel.add(clearButton);

        statusLabel = new JLabel("Ready. Shapes: 0");
        controlPanel.add(buttonPanel, BorderLayout.CENTER);
        controlPanel.add(statusLabel, BorderLayout.SOUTH);

        mainPanel.add(topPanel, BorderLayout.NORTH);
        mainPanel.add(drawingPanel, BorderLayout.CENTER);
        mainPanel.add(controlPanel, BorderLayout.SOUTH);
        setContentPane(mainPanel);
    }

    private void addActionListeners() {
        rectangleButton.addActionListener(new ActionListener() {
            @Override
            public void actionPerformed(ActionEvent e) {
                drawingPanel.setCurrentColor(getSelectedColor());
                int x = (int) (Math.random() * 600);
                int y = (int) (Math.random() * 350);
                drawingPanel.addRectangle(x, y, 100, 80);
                updateStatus();
            }
        });
        circleButton.addActionListener(new ActionListener() {
            @Override
            public void actionPerformed(ActionEvent e) {
                drawingPanel.setCurrentColor(getSelectedColor());
                int x = 60 + (int) (Math.random() * 600);
                int y = 60 + (int) (Math.random() * 350);
                drawingPanel.addCircle(x, y, 50);
                updateStatus();
            }
        });
        clearButton.addActionListener(new ActionListener() {
            @Override
            public void actionPerformed(ActionEvent e) {
                drawingPanel.clear();
                updateStatus();
            }
        });
    }

    private Color getSelectedColor() {
        String selected = (String) colorComboBox.getSelectedItem();
        if ("Red".equals(selected)) {
            return Color.RED;
        } else if ("Green".equals(selected)) {
            return Color.GREEN;
        } else if ("Yellow".equals(selected)) {
            return Color.YELLOW;
        } else if ("Orange".equals(selected)) {
            return new Color(255, 165, 0);
        } else if ("Purple".equals(selected)) {
            return new Color(128, 0, 128);
        } else {
            return Color.BLUE;
        }
    }

    private void updateStatus() {
        statusLabel.setText("Ready. Shapes: " + drawingPanel.getShapeCount());
    }
}

Discussion and analysis

Viva questions (1 of 2)

Why call super.paintComponent(g) first?
Show the answer
It paints the background and clears the previous frame; without it old drawings remain as trails.
Why should you call repaint() instead of paintComponent() directly?
Show the answer
repaint() asks Swing to redraw at the right time on the EDT with a proper Graphics object.

How does the program show polymorphism?
Show the answer
DrawingPanel keeps an ArrayList<Shape> and calls draw(g) on each; Java runs the RectangleShape or CircleShape version.
