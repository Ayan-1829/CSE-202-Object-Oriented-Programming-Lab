Mission 4 · Many enemies, one fight

Your mission

The commander shouts one order: “Attack!” The drone dives, the tank fires a shell, the sniper takes aim. Nobody asked which kind of enemy they were.

They all extend Enemy, so one Enemy[] holds them all, and one call, e.attack(ranger), makes each one attack in its own way. That is polymorphism.

Topic 3 of 6

Method overriding

In the game:
Overriding: each enemy attacks its own way
// Drone
@Override
public void attack(GameCharacter target) {
    target.takeDamage(damage);
    System.out.println(name + " dives at " + target.getName() + "! -" + damage);
}

// Tank
@Override
public void takeDamage(int amount) {
    int blocked = Math.min(armor, amount);
    super.takeDamage(amount - blocked);   // the inherited version does the rest
}
  • A subclass writes its own version of a parent method: same name, same parameters.
  • Mark it with @Override so the compiler checks it.
  • The object’s real class decides which version runs.
  • Same signature as the parent’s method, a new body.

public class Tank extends Enemy {

    public Tank(String name, int armor) {

    }

    // Armor blocks part of every hit, then the inherited version does the rest

Topic 4 of 6

Overloading vs overriding

In the game:
Overloading or overriding?
OverloadingOverriding
Wherein one classin a subclass
Parametersdifferentexactly the same
Chosenat compile time, from the argumentsat run time, from the object
In the gameshoot(target) / shoot(target, power)Drone.attack() / Tank.attack()
  • Overloading: same name, different parameters, usually in one class. Chosen at compile time.
  • Overriding: same name and parameters, in a subclass. Chosen at run time.
  • A class can do both.
  • Overloading gives one class several versions of a method.

public void shoot(Enemy target, int power) {

    if (!target.isAlive()) {
        score += 100;
        System.out.println(target.getName() + " destroyed! Score " + score);
    }
}

@Override
public void describe() {

}
  • Two overloaded shoot() methods.
  • target.takeDamage(power) runs the target’s own version.
  • describe() is overridden.

public class Vehicle {

    // Protected fields are accessible in subclasses
    protected String make;
    protected int year;
    protected int speed;

    public Vehicle(String make, int year) {
        this.make = make;
        this.year = year;
        this.speed = 0;
    }

    public void accelerate(int delta) {
        if (delta > 0) {
            this.speed = this.speed + delta;
        }
    }

    public void brake(int delta) {
        if (delta > 0) {
            this.speed = Math.max(0, this.speed - delta);
        }
    }

    public void display() {
        System.out.println("------- Vehicle -------");
        System.out.println("Make  : " + make);
        System.out.println("Year  : " + year);
        System.out.println("Speed : " + speed + " km/h");
        System.out.println("-----------------------");
    }

    public int getYear() {
        return year;
    }
}
public class Car extends Vehicle {

    private int numDoors;
    private double fuelLevel;

    public Car(String make, int year, int numDoors, double fuelLevel) {
        super(make, year);
        if (numDoors > 0) {
            this.numDoors = numDoors;
        } else {
            this.numDoors = 4;
        }
        if (fuelLevel >= 0.0 && fuelLevel <= 100.0) {
            this.fuelLevel = fuelLevel;
        } else {
            this.fuelLevel = 0.0;
        }
    }

    public void refuel(double amount) {
        if (amount > 0.0) {
            this.fuelLevel = Math.min(100.0, this.fuelLevel + amount);
        }
    }

    @Override
    public void display() {
        System.out.println("------- Car -------");
        System.out.println("Make      : " + make);
        System.out.println("Year      : " + year);
        System.out.println("Speed     : " + speed + " km/h");
        System.out.println("Doors     : " + numDoors);
        System.out.printf("Fuel Level: %.1f%%%n", fuelLevel);
        System.out.println("-------------------");
    }

    public int getNumDoors() { return numDoors; }
    public double getFuelLevel() { return fuelLevel; }
}
public class Motorcycle extends Vehicle {

    private boolean hasStorage;

    public Motorcycle(String make, int year, boolean hasStorage) {
        super(make, year);
        this.hasStorage = hasStorage;
    }

    public void wheelie() {
        System.out.println(make + " is performing a wheelie!");
    }

    @Override
    public void display() {
        System.out.println("------- Motorcycle -------");
        System.out.println("Make        : " + make);
        System.out.println("Year        : " + year);
        System.out.println("Speed       : " + speed + " km/h");
        System.out.println("Has Storage : " + (hasStorage ? "Yes" : "No"));
        System.out.println("--------------------------");
    }

    public boolean hasStorage() { return hasStorage; }
}
public class ElectricCar extends Car {

    private double batteryCapacity;
    private double chargeLevel;

    public ElectricCar(String make, int year, int numDoors,
                       double batteryCapacity, double chargeLevel) {
        super(make, year, numDoors, 100.0);
        if (batteryCapacity > 0.0) {
            this.batteryCapacity = batteryCapacity;
        } else {
            this.batteryCapacity = 50.0;
        }
        if (chargeLevel >= 0.0 && chargeLevel <= 100.0) {
            this.chargeLevel = chargeLevel;
        } else {
            this.chargeLevel = 0.0;
        }
    }

    public void charge(double amount) {
        if (amount > 0.0) {
            this.chargeLevel = Math.min(100.0, this.chargeLevel + amount);
        }
    }

    @Override
    public void display() {
        System.out.println("------- Electric Car -------");
        System.out.println("Make             : " + make);
        System.out.println("Year             : " + year);
        System.out.println("Speed            : " + speed + " km/h");
        System.out.println("Doors            : " + getNumDoors());
        System.out.printf("Battery Capacity : %.1f kWh%n", batteryCapacity);
        System.out.printf("Charge Level     : %.1f%%%n", chargeLevel);
        System.out.println("----------------------------");
    }

    public double getBatteryCapacity() { return batteryCapacity; }
    public double getChargeLevel() { return chargeLevel; }
}
public class Lab4Demo {

    static void displayVehicle(Vehicle vehicle) {
        vehicle.display();
    }

    public static void main(String[] args) {

        // 1. Object Creation
        System.out.println("=== Object Creation ===");
        Vehicle vehicle = new Vehicle("Generic Vehicle", 2020);
        Car car = new Car("Toyota Camry", 2022, 4, 75.0);
        Motorcycle motorcycle = new Motorcycle("Yamaha YZF", 2021, true);
        ElectricCar electricCar = new ElectricCar("Tesla Model 3", 2023, 4, 75.0, 85.0);

        // 2. Direct Method Calls
        System.out.println("\n=== Direct Method Calls ===");
        vehicle.display();
        car.display();
        motorcycle.display();
        electricCar.display();

        // 3. Polymorphism with Superclass References
        System.out.println("\n=== Polymorphic Dispatch ===");
        Vehicle[] vehicles = {vehicle, car, motorcycle, electricCar};
        for (int i = 0; i < vehicles.length; i++) {
            System.out.println("vehicles[" + i + "]:");
            displayVehicle(vehicles[i]);
        }

        // 4. Inherited Methods
        System.out.println("\n=== Inherited Methods ===");
        car.accelerate(50);
        System.out.println("After car.accelerate(50):");
        car.display();
        motorcycle.accelerate(80);
        System.out.println("After motorcycle.accelerate(80):");
        motorcycle.display();
        electricCar.accelerate(40);
        System.out.println("After electricCar.accelerate(40):");
        electricCar.display();

        // 5. Subclass-Specific Methods
        System.out.println("\n=== Subclass-Specific Methods ===");
        car.refuel(20.0);
        System.out.println("After car.refuel(20.0):");
        car.display();
        motorcycle.wheelie();
        electricCar.charge(15.0);
        System.out.println("After electricCar.charge(15.0):");
        electricCar.display();

        // 6. instanceof and Safe Casting
        System.out.println("\n=== instanceof and Safe Casting ===");
        Vehicle v = new Car("Honda Civic", 2021, 2, 60.0);
        System.out.println("v instanceof Vehicle    : " + (v instanceof Vehicle));
        System.out.println("v instanceof Car        : " + (v instanceof Car));
        System.out.println("v instanceof Motorcycle : " + (v instanceof Motorcycle));
        if (v instanceof Car) {
            Car castedCar = (Car) v;
            System.out.println("Number of doors after casting: " + castedCar.getNumDoors());
        }

        // 7. Method Overriding Verification
        System.out.println("\n=== Method Overriding Verification ===");
        Vehicle ref1 = new Car("Ford Mustang", 2020, 2, 50.0);
        Vehicle ref2 = new Motorcycle("Harley-Davidson", 2022, false);
        Vehicle ref3 = new ElectricCar("Nissan Leaf", 2023, 4, 62.0, 70.0);
        ref1.display();
        ref2.display();
        ref3.display();

        // 8. Inherited brake() Method
        System.out.println("\n=== Inherited brake() Method ===");
        Car testCar = new Car("Subaru Outback", 2019, 5, 45.0);
        testCar.accelerate(100);
        System.out.println("After testCar.accelerate(100):");
        testCar.display();
        testCar.brake(30);
        System.out.println("After testCar.brake(30):");
        testCar.display();
        testCar.brake(200);
        System.out.println("After testCar.brake(200):");
        testCar.display();
    }
}

Summary

  • extends builds an is-a tree; subclasses reuse everything above them.
  • super(…) builds the inherited part first; protected shares fields with subclasses.
  • Overriding replaces an inherited method; @Override lets the compiler check it.
  • Superclass references + overriding = polymorphism: one loop, many behaviours.
  • Check instanceof before you cast.
