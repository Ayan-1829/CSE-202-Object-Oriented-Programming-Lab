Constructor chaining with this(…)
public Weapon() {

public Weapon(String name, int damage) {

    this.damage = damage;
    this.ammo = ammo;

  • this(…) calls another constructor of the same class.
  • It must be the first line of the constructor.
  • The real work is written once, in one constructor.

Method overloading

System.out.println("\n=== Overloaded shoot() ===");
Player ranger = new Player("Ranger");
ranger.equip(rocket);
ranger.shoot();
ranger.shoot("Tank");
ranger.shoot("Drone", 3);
  • Several methods share one name but have different parameter lists.
  • Java picks the one whose parameters match the call.
  • The return type alone is not enough to tell them apart.
  • The rocket has 3 ammo: the third call runs dry halfway through the burst.

Three shoot() methods

// Overloaded shoot(): same name, different parameter lists
public void shoot() {
    if (weapon.fire()) {
        System.out.println(name + " fires the " + weapon.getName() + " into the air");
    } else {
        System.out.println(name + ": click! The " + weapon.getName() + " is empty");
    }
}

public void shoot(String target) {
    if (weapon.fire()) {
        System.out.println(name + " hits " + target + " for " + weapon.getDamage());
    } else {
        System.out.println(name + ": click! The " + weapon.getName() + " is empty");
    }
}

public void shoot(String target, int burst) {
    System.out.println(name + " fires a burst of " + burst + " at " + target);
    for (int i = 1; i <= burst; i++) {
        shoot(target);                  // reuses the one-target version
    }
}
  • Same name, three parameter lists.
  • The burst version reuses shoot(target).

Topic 4 of 5

Passing arguments

In the game:
Passing a primitive and passing a reference
  • Java always passes a copy of the argument.
  • For a primitive, the copy is the value: the caller’s variable cannot change.
  • For an object, the copy is the reference: the method reaches the same object.

Topic 4 of 5 · in the game

Passing a primitive and passing a reference

Topic 4 of 5 · our game program · 1 of 2 · ArmoryDemo.java

Primitive and reference parameters

// Receives a copy of the int: the change stays inside this method
static void refill(int ammo) {
    ammo = 99;
    System.out.println("  inside refill(int): ammo = " + ammo);
}

// Receives a copy of the reference: both point at the same Weapon object
static void refill(Weapon w) {
    w.addAmmo(10);
    System.out.println("  inside refill(Weapon): " + w);
}

// Pointing the parameter at a new object does not change the caller's variable
static void swap(Weapon w) {
    w = new Weapon("Water gun", 1, 1);
    System.out.println("  inside swap(): w is now " + w);
}
  • refill(int) and refill(Weapon) overload each other too.
  • swap re-points its own copy only.

Topic 5 of 5

Objects working on other objects

In the game:
A medic heals through a reference
public void heal(Player p, int amount) {
    p.setHealth(p.getHealth() + amount);
}

// in main
ranger.takeDamage(40);        // health 60
doc.heal(ranger, 30);         // p and ranger: the same Player
ranger.getHealth();           // 90
  • A method can take another object as a parameter.
  • Through that reference it can call the other object’s methods and change it.
  • In the game: a Medic heals a Player.
  • p is a copy of the reference in ranger.

public class Rectangle {

    private double width;
    private double height;
    private String colour;

    public Rectangle() {
        this(1.0, 1.0, "White");
    }

    public Rectangle(double side) {
        this(side, side, "White");
    }

    public Rectangle(double width, double height) {
        this(width, height, "White");
    }

    public Rectangle(double width, double height, String colour) {
        if (width > 0) {
            this.width = width;
        } else {
            this.width = 1.0;
        }
        if (height > 0) {
            this.height = height;
        } else {
            this.height = 1.0;
        }
        this.colour = colour;
    }

    // Copy constructor
    public Rectangle(Rectangle other) {
        this(other.width, other.height, other.colour);
    }

    public double area() {
        return width * height;
    }

    public double area(double scaleFactor) {
        return area() * scaleFactor;
    }

    public static double area(double width, double height) {
        return width * height;
    }

    public String describe() {
        return String.format("Rectangle[%.2f x %.2f, colour=%s, area=%.2f]",
                width, height, colour, area());
    }

    public String describe(String prefix) {
        return prefix + ": " + describe();
    }

    public void scale(double factor) {
        if (factor > 0) {
            width = width * factor;
            height = height * factor;
        }
    }

    public double getWidth() { return width; }
    public double getHeight() { return height; }
    public String getColour() { return colour; }
    public void setColour(String colour) { this.colour = colour; }

    @Override
    public String toString() {
        return describe();
    }
}
public class Lab3Demo {

    static void passPrimitive(double side) {
        System.out.println("Inside passPrimitive: side before = " + side);
        side = side * 2;
        System.out.println("Inside passPrimitive: side after  = " + side);
    }

    static void passReference(Rectangle rectangle) {
        System.out.println("Inside passReference before scaling: " + rectangle.describe());
        rectangle.scale(2.0);
        System.out.println("Inside passReference after scaling : " + rectangle.describe());
    }

    static void tryReassignReference(Rectangle rectangle) {
        rectangle = new Rectangle(99.0, 99.0, "Invisible");
        System.out.println("Inside tryReassignReference: " + rectangle.describe());
    }

    public static void main(String[] args) {

        // 1. Constructor Variants
        System.out.println("=== Constructor Variants ===");
        Rectangle r0 = new Rectangle();
        System.out.println("Default constructor    : " + r0.describe());
        Rectangle r1 = new Rectangle(5.0);
        System.out.println("Square constructor     : " + r1.describe());
        Rectangle r2 = new Rectangle(4.0, 7.0);
        System.out.println("Two-arg constructor    : " + r2.describe());
        Rectangle r3 = new Rectangle(3.0, 6.0, "Blue");
        System.out.println("Full constructor       : " + r3.describe());
        Rectangle r4 = new Rectangle(r3);
        System.out.println("Copy constructor       : " + r4.describe());

        // 2. Copy Constructor Independence
        System.out.println("\n=== Copy Constructor Independence ===");
        r3.setColour("Green");
        System.out.println("Original after change  : " + r3.describe());
        System.out.println("Copy remains unchanged : " + r4.describe());

        // 3. Method Overloading
        System.out.println("\n=== Method Overloading: area() ===");
        Rectangle rect = new Rectangle(6.0, 4.0, "Yellow");
        System.out.printf("area()          = %.2f%n", rect.area());
        System.out.printf("area(1.5)       = %.2f%n", rect.area(1.5));
        System.out.printf("area(3.0, 8.0)  = %.2f%n", Rectangle.area(3.0, 8.0));

        System.out.println("\n=== Method Overloading: describe() ===");
        System.out.println(rect.describe());
        System.out.println(rect.describe("Main rectangle"));

        // 4. Passing Primitive Value
        System.out.println("\n=== Passing a Primitive Value ===");
        double side = 10.0;
        System.out.println("Before method call: side = " + side);
        passPrimitive(side);
        System.out.println("After method call : side = " + side);

        // 5. Passing Object Reference
        System.out.println("\n=== Passing an Object Reference ===");
        Rectangle ref = new Rectangle(5.0, 5.0, "Blue");
        System.out.println("Before method call: " + ref.describe());
        passReference(ref);
        System.out.println("After method call : " + ref.describe());

        // 6. Reassigning Reference Parameter
        System.out.println("\n=== Reassigning Reference Parameter ===");
        Rectangle original = new Rectangle(2.0, 3.0, "Pink");
        System.out.println("Before method call: " + original.describe());
        tryReassignReference(original);
        System.out.println("After method call : " + original.describe());
    }
}

refill(ammo) set ammo to 99, but main still printed 5. Why?
Show the answer
The method got a copy of the value. Its ammo is a different variable from main’s.
swap(pistol) made a water gun, but main’s pistol did not change. Why?
Show the answer
swap got a copy of the reference and pointed its copy at a new object. main’s variable still refers to the old one.
