Mission 1 · The numbers behind the game

Your mission

Every game you have played is secretly a spreadsheet in a hurry. Behind the explosions, the computer is just updating a few numbers, sixty times a second.

Health 100, ammo 5, score 0, name “Ranger”: in Java each one lives in a variable with a type. Add if and switch to make decisions and loops to repeat them, and the numbers start to fight back.

Topic 3 of 6

Type casting

In the game:
Type casting: damage into health
int hit = (int) damage;                 // narrowing: 12.75 -> 12
health = health - hit;                  // 100 - 12 = 88
double healthAsDouble = health;         // widening: 88 -> 88.0
char nextRank = (char) (rank - 1);      // 'B' - 1 = 'A'
  • Widening: a small type goes into a bigger one by itself (int → double).
  • Narrowing: a bigger type into a smaller one needs a cast, (int), and drops the fraction.
  • Watch int ÷ int: 7 / 2 is 3. Cast one side to get 3.5.
  • The cast truncates: 12.75 becomes 12, not 13.

Topic 4 of 6

The if-else statement

In the game:
if / else: the health bar colour
if (health >= 70) {
    System.out.println(health + " HP: Healthy (green bar)");
} else if (health >= 30) {
    System.out.println(health + " HP: Hurt (yellow bar)");
} else if (health > 0) {
    System.out.println(health + " HP: Critical (red bar)");
} else {
    System.out.println("Game over");
}
  • if runs a block only when its condition is true.
  • else if tests the next condition; else catches the rest.
  • Only the first true branch runs.
  • 88 HP: the first test is true, so the other branches are skipped.

The switch statement

In the game:
switch: pick a weapon
GameBasics.java
·
Weapon select
// 4. switch: key 2 picks the rifle
int key = 2;
switch (key) {
    case 1:  System.out.println("Weapon: Pistol"); break;
    case 2:  System.out.println("Weapon: Rifle");  break;
    default: System.out.println("Weapon: Fists");
}
  • switch picks one case by the value of a variable.
  • break ends the case; without it the next case runs too (fall-through).
  • default runs when no case matches.
  • key 2 jumps straight to case 2; break stops it there.

Loops

In the game:
Loops: fire, fire, fire
GameBasics.java
·
Burst fire
// 5. for: a burst of exactly 3 shots
for (int shot = 1; shot <= 3; shot++) {
    ammo--;
    System.out.println("Shot " + shot + ", ammo left " + ammo);
}
  • A loop repeats a block of code. for (start; test; update): you know how many times.
  • while tests first (may run zero times); do-while tests after (runs at least once).
  • break leaves the loop at once; continue skips to the next round.
  • Exactly three shots: start, test and update all sit in the header.

A jam and an empty clip

// 7. break and continue: a jammed shot, then an empty clip
for (int shot = 1; shot <= 5; shot++) {
    if (shot == 2) continue;            // jammed: skip this shot
    if (ammo == 0) break;               // empty: stop firing
    ammo--;
    System.out.println("Bang! ammo left " + ammo);
}
  • continue skips shot 2; break stops when ammo is 0.

Build the game · 1 file

The complete game program

public class GameBasics {
    public static void main(String[] args) {

        // 1. Variables: the player's stats
        String name = "Ranger";
        int health = 100;
        int ammo = 5;
        double damage = 12.75;
        boolean alive = true;
        System.out.println(name + " | health " + health + " | ammo " + ammo + " | alive " + alive);

        // 2. Casting: a 12.75 hit becomes a whole number
        int hit = (int) damage;
        health = health - hit;
        System.out.println("Hit for " + damage + " -> loses " + hit + " -> health " + health);

        // 3. if-else: the colour of the health bar
        if (health >= 70) {
            System.out.println("Health bar: green");
        } else if (health >= 30) {
            System.out.println("Health bar: yellow");
        } else {
            System.out.println("Health bar: red");
        }

        // 4. switch: key 2 picks the rifle
        int key = 2;
        switch (key) {
            case 1:  System.out.println("Weapon: Pistol"); break;
            case 2:  System.out.println("Weapon: Rifle");  break;
            default: System.out.println("Weapon: Fists");
        }

        // 5. for: a burst of exactly 3 shots
        for (int shot = 1; shot <= 3; shot++) {
            ammo--;
            System.out.println("Shot " + shot + ", ammo left " + ammo);
        }

        // 6. while: shoot the drone until it falls
        int droneHealth = 60;
        while (droneHealth > 0) {
            droneHealth -= 25;
            System.out.println("Drone health " + Math.max(droneHealth, 0));
        }

        // 7. break and continue: a jammed shot, then an empty clip
        for (int shot = 1; shot <= 5; shot++) {
            if (shot == 2) continue;            // jammed: skip this shot
            if (ammo == 0) break;               // empty: stop firing
            ammo--;
            System.out.println("Bang! ammo left " + ammo);
        }

        // 8. do-while: fight waves until no enemies are left
        int enemies = 5;
        int wave = 0;
        do {
            wave++;
            enemies -= 3;
            System.out.println("Wave " + wave + " cleared");
        } while (enemies > 0);
    }
}

Official lab · 1 file

The official program

public class Lab1Demo {
    public static void main(String[] args) {

        // 1. Primitive Data Types and String
        byte byteVal = 100;
        short shortVal = 30000;
        int age = 21;
        long bigNum = 9876543210L;
        float gpa = 3.75f;
        double height = 5.91;
        char initial = 'A';
        boolean isStudent = true;
        String name = "Mozdaher Abdul Quader";

        System.out.println("=== Primitive Data Types and String ===");
        System.out.println("byte    : " + byteVal);
        System.out.println("short   : " + shortVal);
        System.out.println("int     : " + age);
        System.out.println("long    : " + bigNum);
        System.out.println("float   : " + gpa);
        System.out.println("double  : " + height);
        System.out.println("char    : " + initial + " (Unicode = " + (int) initial + ")");
        System.out.println("boolean : " + isStudent);
        System.out.println("String  : " + name);

        // 2. Type Casting
        System.out.println("\n=== Type Casting ===");
        double ageAsDouble = age;
        System.out.println("int " + age + " widened to double: " + ageAsDouble);

        double pi = 3.14159;
        int piTruncated = (int) pi;
        System.out.println("double " + pi + " narrowed to int: " + piTruncated);

        char letter = 'Z';
        int code = letter;
        char nextChar = (char) (code + 1);
        System.out.println("char 'Z' as int: " + code + " | next char: " + nextChar);

        // 3. Conditional Statement
        System.out.println("\n=== Conditional Statement ===");
        int n = 42;
        if (n > 0) {
            System.out.println(n + " is Positive");
        } else if (n == 0) {
            System.out.println(n + " is Zero");
        } else {
            System.out.println(n + " is Negative");
        }

        double weightKg = 70.0;
        double heightM = 1.75;
        double bmi = weightKg / (heightM * heightM);
        System.out.printf("BMI = %.2f => ", bmi);
        if (bmi < 18.5) {
            System.out.println("Underweight");
        } else if (bmi < 25.0) {
            System.out.println("Normal weight");
        } else if (bmi < 30.0) {
            System.out.println("Overweight");
        } else {
            System.out.println("Obese");
        }

        // 4. Switch Statement
        System.out.println("\n=== Switch Statement: Grade Classifier ===");
        int score = 85;
        char grade;
        switch (score / 10) {
            case 10:
            case 9:
                grade = 'A';
                break;
            case 8:
                grade = 'B';
                break;
            case 7:
                grade = 'C';
                break;
            case 6:
                grade = 'D';
                break;
            default:
                grade = 'F';
        }
        System.out.println("Score: " + score + " => Grade: " + grade);

        // 5. For Loop
        System.out.println("\n=== For Loop: Summation 1 to n ===");
        int upperBound = 10;
        int sum = 0;
        for (int i = 1; i <= upperBound; i++) {
            sum = sum + i;
        }
        System.out.println("Sum of 1 to " + upperBound + " = " + sum);

        System.out.print("Even numbers from 1 to 20, skipping multiples of 6: ");
        for (int i = 1; i <= 20; i++) {
            if (i % 6 == 0) {
                continue;
            }
            if (i > 18) {
                break;
            }
            if (i % 2 == 0) {
                System.out.print(i + " ");
            }
        }
        System.out.println();

        // 6. While Loop
        System.out.println("\n=== While Loop: Reverse Digits ===");
        int number = 12345;
        int temp = number;
        int reversed = 0;
        while (temp != 0) {
            int digit = temp % 10;
            reversed = reversed * 10 + digit;
            temp = temp / 10;
        }
        System.out.println("Original number: " + number);
        System.out.println("Reversed number: " + reversed);

        // 7. Do-While Loop
        System.out.println("\n=== Do-While Loop: Collatz Sequence ===");
        long collatz = 27;
        int steps = 0;
        System.out.print("Sequence: ");
        do {
            System.out.print(collatz + " ");
            if (collatz % 2 == 0) {
                collatz = collatz / 2;
            } else {
                collatz = 3 * collatz + 1;
            }
            steps++;
        } while (collatz != 1);
        System.out.println("1");
        System.out.println("Steps to reach 1: " + steps);
    }
}

Summary

  • A game is numbers and words in variables; the type decides what fits.
  • double → int needs a cast and drops the fraction; int → double is automatic.
  • if-else chooses by condition; switch chooses by value (remember break).
  • for: a known number of times. while: while a condition holds. do-while: at least once.
