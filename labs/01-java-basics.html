Before we start

Why this lab

Every Java program you write this semester — bank systems, threads, GUIs — is built from the same few pieces. Which ones?

Variables hold data, types say what kind of data, decisions choose a path and loops repeat work. This lab puts all of them in one program, Lab1Demo.

Theory 1 of 6

From .java to a running program

  • You write Lab1Demo.java; javac compiles it to bytecode in Lab1Demo.class.
  • The JVM loads the bytecode and starts at main: “write once, run anywhere”.
  • A public class must live in a file with the same name.

Theory 4 of 6

Type casting

  • Widening (small → large) is automatic and safe.
  • Narrowing needs a cast and may lose data: the fraction is cut off, not rounded.

Type casting

double d = 25;            // widening: automatic -> 25.0
int price = (int) 99.99;  // narrowing: explicit -> 99

Theory 5 of 6

Decisions: if-else and switch

  • Use if / else if / else for ranges and conditions.
  • Use switch to compare one value against fixed cases; forget break and execution falls through.

Decisions: if-else and switch

switch (score / 10) {
    case 10: case 9: grade = 'A'; break;
    case 8:          grade = 'B'; break;
    default:         grade = 'F';
}

Theory 6 of 6

Loops, break and continue

  • for: number of iterations known in advance (summation).
  • while: repeat while a condition holds (reverse digits).
  • do-while: body runs at least once (Collatz sequence).
  • break leaves the loop; continue skips to the next iteration.

Implementation design

Execution flow

  1. Declare and print the eight primitive variables and a String
  2. Widen an int to double, narrow a double to int, convert char ↔ int
  3. Classify a number (positive/zero/negative) and a BMI with if-else
  4. Assign a letter grade with switch
  5. Sum 1..10 with for; print even numbers using continue and break
  6. Reverse digits with while
  7. Print the Collatz sequence of 27 with do-while

Single class, everything inside main: the focus is syntax, not objects.

Widening and narrowing casts

    System.out.println("Overweight");

}
  • Each test only needs the upper bound: earlier branches already ruled out smaller values.
  • printf("%.2f") prints two decimals.

Code walkthrough 6 of 10 · Lab1Demo.java

switch with fall-through

int score = 85;
char grade;
switch (score / 10) {
    case 10:
    case 9:
        grade = 'A';
        break;
    case 8:
        grade = 'B';
        break;
    case 7:
        grade = 'C';
        break;
    case 6:
        grade = 'D';
        break;
    default:
        grade = 'F';
}
  • score / 10 is integer division: 85 → 8.
  • case 10: has no break, so it falls through to case 9.
  • default catches everything else.

System.out.print("Even numbers from 1 to 20, skipping multiples of 6: ");
for (int i = 1; i <= 20; i++) {
    if (i % 6 == 0) {
        continue;

while loop: reverse the digits

// 6. While Loop
System.out.println("\n=== While Loop: Reverse Digits ===");
int number = 12345;
int temp = number;
int reversed = 0;
while (temp != 0) {
    int digit = temp % 10;
    reversed = reversed * 10 + digit;
    temp = temp / 10;
}
System.out.println("Original number: " + number);
System.out.println("Reversed number: " + reversed);
  • % 10 takes the last digit; / 10 removes it.
  • The loop runs until no digits are left.

Code walkthrough 10 of 10 · Lab1Demo.java

do-while: the Collatz sequence

// 7. Do-While Loop
System.out.println("\n=== Do-While Loop: Collatz Sequence ===");
long collatz = 27;
int steps = 0;
System.out.print("Sequence: ");
do {
    System.out.print(collatz + " ");
    if (collatz % 2 == 0) {
        collatz = collatz / 2;
    } else {
        collatz = 3 * collatz + 1;
    }
    steps++;
} while (collatz != 1);
System.out.println("1");
System.out.println("Steps to reach 1: " + steps);
  • The body runs before the test, so 27 is printed first.
  • Even → halve; odd → 3n + 1; stop at 1.

Discussion and analysis

Viva questions (1 of 2)

Why is Java called statically typed, and how does that help?
Show the answer
Every variable must be declared with a type before use, so the compiler catches type errors (for example assigning 3.7 to an int without a cast) before the program runs.
What does (int) 99.99 give, and why must the cast be written?
Show the answer
99. Narrowing can lose data (the fraction is truncated), so Java makes you state it explicitly.

Discussion and analysis

Viva questions (2 of 2)

When would you choose do-while over while?
Show the answer
When the body must run at least once, such as showing a menu or the first value of the Collatz sequence.
What happens if you remove a break from a switch case?
Show the answer
Execution falls through into the next case and runs its statements too, until a break or the end of the switch.
