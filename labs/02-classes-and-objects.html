Topic 2 of 6

Fields, constructor and this

public class Enemy {
    private String type;
    private int health;
    private int points;

    public Enemy(String type, int health, int points) {
        this.type = type;
        this.health = health;
        this.points = points;
    }
}
  • Fields are the variables inside an object.
  • A constructor has the class name and no return type; it fills the fields when new runs.
  • this.health means “this object’s field” when a parameter has the same name.
  • Fields hold each object’s state.

Methods

In the game:
Methods: what objects can do
ranger.shoot(drone1);          // the player acts on a drone

// inside Player.shoot(Enemy target):
ammo--;
target.takeDamage(25);         // the drone changes its own health
if (!target.isAlive()) {
    score += target.getPoints();
}
  • A method is something an object can do.
  • It may take parameters and may return a value (void returns nothing).
  • Call it on an object: c.increment().
  • A method is called on an object: ranger.shoot(…).

shoot(): one object acts on another

public void shoot(Enemy target) {
    if (!target.isAlive()) {
        System.out.println(name + " holds fire: " + target.getType() + " is already destroyed");
        return;
    }
    if (ammo == 0) {
        System.out.println(name + " pulls the trigger: click! Out of ammo");
        return;
    }
    ammo--;
    target.takeDamage(25);
    System.out.println(name + " shoots " + target.getType() + " -> its health " + target.getHealth());
    if (!target.isAlive()) {
        score += target.getPoints();
        System.out.println(target.getType() + " destroyed! +" + target.getPoints() + " points");
    }
}
  • Two early returns: a destroyed target, an empty clip.
  • target.takeDamage(25) changes the drone, not the player.
  • Points are added only when the shot destroys it.

Topic 4 of 6

Encapsulation

In the game:
Encapsulation: private fields and a validating setter
private int health;

public int getHealth() { return health; }

public void setHealth(int health) {
    if (health < 0) {
        health = 0;
    }
    if (health > 100) {
        health = 100;
    }
    this.health = health;
}
  • Make fields private: only the class itself can touch them.
  • Give controlled access with public getters and setters.
  • A setter can refuse bad values.
  • private: only code inside the class can touch the field.

Getters and the validating setter

// Getters: read-only access to private fields
public String getName() { return name; }
public int getHealth()  { return health; }
public int getAmmo()    { return ammo; }
public int getScore()   { return score; }
public static int getPlayersCreated() { return playersCreated; }

// Validating setter: health always stays between 0 and 100
public void setHealth(int health) {
    if (health < 0) {
        health = 0;
    }
    if (health > 100) {
        health = 100;
    }
    this.health = health;
}
  • Getters give read-only access.
  • The setter clamps health to 0..100.

Topic 5 of 6

Instance and static members

In the game:
Instance members and static members
private int health;                      // one per object
private static int enemiesSpawned = 0;   // one for the whole class

public Enemy(String type, int health, int points) {
    …
    enemiesSpawned++;                    // counts every new Enemy
}

int n = Enemy.getEnemiesSpawned();       // called on the class
  • An instance field: every object has its own copy (each drone’s health).
  • A static field: one copy shared by the whole class (how many enemies were spawned).
  • Use a static member through the class name: Enemy.enemiesSpawned.
  • An instance field belongs to each object.

public class Enemy {

  • enemiesSpawned++ runs once per new Enemy.

public class Player {
    // Fields: every Player object gets its own copy
    private String name;
    private int health;
    private int ammo;
    private int score;

    // Static field: one copy shared by the whole class
    private static int playersCreated = 0;

    // Constructor: runs once for each new Player
    public Player(String name, int health, int ammo) {
        this.name = name;
        setHealth(health);
        this.ammo = ammo;
        this.score = 0;
        playersCreated++;
    }

    // Getters: read-only access to private fields
    public String getName() { return name; }
    public int getHealth()  { return health; }
    public int getAmmo()    { return ammo; }
    public int getScore()   { return score; }
    public static int getPlayersCreated() { return playersCreated; }

    // Validating setter: health always stays between 0 and 100
    public void setHealth(int health) {
        if (health < 0) {
            health = 0;
        }
        if (health > 100) {
            health = 100;
        }
        this.health = health;
    }

    // Methods: what a player can do
    public void shoot(Enemy target) {
        if (!target.isAlive()) {
            System.out.println(name + " holds fire: " + target.getType() + " is already destroyed");
            return;
        }
        if (ammo == 0) {
            System.out.println(name + " pulls the trigger: click! Out of ammo");
            return;
        }
        ammo--;
        target.takeDamage(25);
        System.out.println(name + " shoots " + target.getType() + " -> its health " + target.getHealth());
        if (!target.isAlive()) {
            score += target.getPoints();
            System.out.println(target.getType() + " destroyed! +" + target.getPoints() + " points");
        }
    }

    public void takeDamage(int amount) {
        setHealth(health - amount);
    }

    public boolean isAlive() {
        return health > 0;
    }

    public void showStatus() {
        System.out.println("[" + name + "] health " + health + " | ammo " + ammo + " | score " + score);
    }
}

public class BattleDemo {
    public static void main(String[] args) {

        System.out.println("=== Creating objects with new ===");
        Player ranger = new Player("Ranger", 100, 5);
        Enemy drone1 = new Enemy("Drone-1", 40, 50);
        Enemy drone2 = new Enemy("Drone-2", 40, 50);
        ranger.showStatus();
        System.out.println("Players created: " + Player.getPlayersCreated());
        System.out.println("Enemies spawned: " + Enemy.getEnemiesSpawned());

        System.out.println("\n=== Each object keeps its own state ===");
        ranger.shoot(drone1);
        System.out.println("drone1 health: " + drone1.getHealth());

        System.out.println("\n=== The fight: objects calling each other's methods ===");
        drone2.attack(ranger);
        ranger.shoot(drone1);
        drone2.attack(ranger);
        ranger.shoot(drone2);
        ranger.shoot(drone1);
        ranger.shoot(drone2);
        ranger.shoot(drone2);
        ranger.showStatus();

        System.out.println("\n=== Encapsulation: the setter validates ===");

}
