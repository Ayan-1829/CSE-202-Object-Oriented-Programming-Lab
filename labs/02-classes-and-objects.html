Topic 2 of 6

Fields, constructor and this

public class Enemy {
    private String type;
    private int health;
    private int points;

    public Enemy(String type, int health, int points) {
        this.type = type;
        this.health = health;
        this.points = points;
    }
}
  • Fields are the variables inside an object.
  • A constructor has the class name and no return type; it fills the fields when new runs.
  • this.health means “this object’s field” when a parameter has the same name.
  • Fields hold each object’s state.

Methods

In the game:
Methods: what objects can do

  • A method is something an object can do.
  • It may take parameters and may return a value (void returns nothing).
  • Call it on an object: c.increment().

shoot(): one object acts on another

public void shoot(Enemy target) {
    if (!target.isAlive()) {
        System.out.println(name + " holds fire: " + target.getType() + " is already destroyed");
        return;
    }
    if (ammo == 0) {
        System.out.println(name + " pulls the trigger: click! Out of ammo");
        return;
    }
    ammo--;
    target.takeDamage(25);
    System.out.println(name + " shoots " + target.getType() + " -> its health " + target.getHealth());
    if (!target.isAlive()) {
        score += target.getPoints();
        System.out.println(target.getType() + " destroyed! +" + target.getPoints() + " points");
    }
}
  • Two early returns: a destroyed target, an empty clip.
  • target.takeDamage(25) changes the drone, not the player.
  • Points are added only when the shot destroys it.

Topic 4 of 6

Encapsulation

In the game:
Encapsulation: private fields and a validating setter
private int health;

public int getHealth() { return health; }

public void setHealth(int health) {
    if (health < 0) {
        health = 0;
    }
    if (health > 100) {
        health = 100;
    }
    this.health = health;
}
  • Make fields private: only the class itself can touch them.
  • Give controlled access with public getters and setters.
  • A setter can refuse bad values.
  • private: only code inside the class can touch the field.

Getters and the validating setter

// Getters: read-only access to private fields
public String getName() { return name; }
public int getHealth()  { return health; }
public int getAmmo()    { return ammo; }
public int getScore()   { return score; }
public static int getPlayersCreated() { return playersCreated; }

// Validating setter: health always stays between 0 and 100
public void setHealth(int health) {
    if (health < 0) {
        health = 0;
    }
    if (health > 100) {
        health = 100;
    }
    this.health = health;
}
  • Getters give read-only access.
  • The setter clamps health to 0..100.

Topic 5 of 6

Instance and static members

In the game:
Instance members and static members
private int health;                      // one per object
private static int enemiesSpawned = 0;   // one for the whole class

public Enemy(String type, int health, int points) {
    …
    enemiesSpawned++;                    // counts every new Enemy
}

int n = Enemy.getEnemiesSpawned();       // called on the class
  • An instance field: every object has its own copy (each drone’s health).
  • A static field: one copy shared by the whole class (how many enemies were spawned).
  • Use a static member through the class name: Enemy.enemiesSpawned.
  • An instance field belongs to each object.

        this.name = name;
        setHealth(health);
        this.ammo = ammo;
        this.score = 0;
        playersCreated++;

The official program

public class Car {

    // Private instance fields
    private String make;
    private int speed;
    private double fuelLevel;

    // Static field shared by all Car objects
    private static int count = 0;

    public Car(String make, double fuelLevel) {
        this.make = make;
        this.speed = 0;
        if (fuelLevel >= 0.0 && fuelLevel <= 100.0) {
            this.fuelLevel = fuelLevel;
        } else {
            this.fuelLevel = 0.0;
        }
        count++;
    }

    public void accelerate(int delta) {
        if (delta > 0) {
            this.speed = this.speed + delta;
        }
    }

    public void brake(int delta) {
        if (delta > 0) {
            this.speed = Math.max(0, this.speed - delta);
        }
    }

    public void refuel(double amount) {
        if (amount > 0.0) {
            this.fuelLevel = Math.min(100.0, this.fuelLevel + amount);
        }
    }

    public void display() {
        System.out.println("-------------------------------");
        System.out.println("Make      : " + make);
        System.out.println("Speed     : " + speed + " km/h");
        System.out.printf("Fuel Level: %.1f%%%n", fuelLevel);
        System.out.println("-------------------------------");
    }

    // Getter methods
    public String getMake() { return make; }
    public int getSpeed() { return speed; }
    public double getFuelLevel() { return fuelLevel; }

    // Setter methods
    public void setMake(String make) { this.make = make; }

    public void setFuelLevel(double fuelLevel) {
        if (fuelLevel >= 0.0 && fuelLevel <= 100.0) {
            this.fuelLevel = fuelLevel;
        }
    }

    // Static method
    public static int getCount() { return count; }
}
public class Lab2Demo {

    public static void main(String[] args) {

        // 1. Object Creation
        System.out.println("=== Object Creation ===");
        Car car1 = new Car("Sedan", 80.5);
        Car car2 = new Car("SUV", 100.0);
        System.out.println("Total Car objects created: " + Car.getCount());

        // 2. Method Invocation on car1
        System.out.println("\n=== car1 initial state ===");
        car1.display();
        car1.accelerate(30);
        System.out.println("After accelerate(30):");
        car1.display();
        car1.brake(10);
        System.out.println("After brake(10):");
        car1.display();
        car1.brake(100);
        System.out.println("After brake(100):");
        car1.display();

        // 3. Method Invocation on car2
        System.out.println("\n=== car2 initial state ===");
        car2.display();
        car2.accelerate(60);
        car2.refuel(5.0);
        System.out.println("After accelerate(60) and refuel(5.0):");
        car2.display();

        // 4. Getters and Setters
        System.out.println("\n=== Getters and Setters ===");
        System.out.println("car1 make via getter : " + car1.getMake());
        System.out.println("car2 speed via getter: " + car2.getSpeed());
        car1.setMake("Hatchback");
        System.out.println("car1 make after setter: " + car1.getMake());

        // 5. Reference Semantics
        System.out.println("\n=== Reference Semantics ===");
        Car car3 = car1;
        car3.accelerate(20);
        System.out.println("car1.getSpeed() = " + car1.getSpeed());
        System.out.println("car3.getSpeed() = " + car3.getSpeed());
        System.out.println("car1 and car3 refer to the same object.");

        // 6. Static Member
        System.out.println("\n=== Static Member ===");
        System.out.println("Total Car objects ever created: " + Car.getCount());
    }
}
