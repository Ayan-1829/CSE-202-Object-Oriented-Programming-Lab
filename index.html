Object Oriented Programming Lab

Learn Java by building a game. In ten chapters, Code Commando grows from a few variables into a full Swing game with threads and animation. Each chapter explains its topic through the game, walks through a real program, gives game practice tasks, and then the official lab program with its graded tasks and report exercises.

Inside a chapter: ← → or Space to move, F for full screen, M for the slide list. Click a game before using the keyboard in it; on a phone, use the on-screen buttons. Checklists are saved in this browser.

  • 1Lab IJava Syntax, Data Types & Control FlowMission 1 · The numbers behind the gameMeet Code Commando, the game we build this semester. Start with its numbers: variables and types for health, ammo and score, a cast for damage, if and switch for decisions, and loops for firing.51 slides · 3 game tasks · 4 official in-lab tasks · 2 report exercises
  • 2Lab IIClasses, Objects, Instances & MethodsMission 2 · Build the charactersTurn the commando and the drones into objects. One class is the blueprint, every object keeps its own health. Fields, constructors, methods, encapsulation, static members and references.42 slides · 3 game tasks · 3 official in-lab tasks · 2 report exercises
  • 3Lab IIIConstructors, Overloading & Reference PassingMission 3 · Arm upBuild an armory: default, parameterised and copy constructors for Weapon, chaining with this(…), an overloaded shoot(), and what really happens when you pass an int or a Weapon to a method.44 slides · 3 game tasks · 3 official in-lab tasks · 2 report exercises
  • 4Lab IVInheritance, Polymorphism & OverridingMission 4 · Many enemies, one fightDrones, tanks and snipers are all enemies, and enemies and the player are all game characters. Inheritance shares the common code, overriding gives each enemy its own attack, and polymorphism runs a whole wave with one loop.45 slides · 3 game tasks · 3 official in-lab tasks · 2 report exercises
  • 5Lab VAbstract Classes & InterfacesMission 5 · Rules every object followsEverything on screen is a GameObject that must update() itself and say how it looks, yet nobody can create a plain GameObject. Interfaces add abilities across the tree: Damageable, Shooter and Collectible.47 slides · 3 game tasks · 3 official in-lab tasks · 2 report exercises
  • 6Lab VIException Handling & Custom ExceptionsMission 6 · When things go wrongA gun runs out of ammo, a player types a level that does not exist, a lane number is out of range. Exceptions let the game notice the problem, deal with it and keep running.43 slides · 3 game tasks · 3 official in-lab tasks · 2 report exercises
  • 7Lab VIIThread Creation & Thread StatesMission 7 · Everything at onceIn a real game the enemy spawner, the ammo regeneration and the countdown timer all run at the same time. Each one is a thread. Create threads two ways, start them, watch their states and wait for them with join().41 slides · 3 game tasks · 3 official in-lab tasks · 2 report exercises
  • 8Lab VIIISynchronization, Deadlock & Resource AllocationMission 8 · Sharing safelyThe squad shares one scoreboard, one ammo crate and one med kit. Without care, points get lost and soldiers freeze. Race conditions, synchronized, deadlock and its fix, and wait/notify for supply drops.43 slides · 3 game tasks · 3 official in-lab tasks · 2 report exercises
  • 9Lab IXGUI Components, Drawing, AWT & SwingMission 9 · Put the game on screenLeave the console behind. A JFrame window, a score label, Fire and Reset buttons, and a JPanel that draws the commando and the drones from rectangles and ovals, then reacts to the keyboard.47 slides · 3 game tasks · 3 official in-lab tasks · 2 report exercises
  • 10Lab XAnimation with ThreadsMission 10 · Bring it to lifeThe finished game. A game-loop thread updates every object about 60 times a second, Rectangle collisions decide what is hit, drones bob, tanks fire shells, and Swing paints each frame. Every chapter so far comes together here.57 slides · 3 game tasks · 3 official in-lab tasks · 2 report exercises

Requirements: JDK 11 or later and an IDE such as NetBeans, Eclipse or IntelliJ IDEA. Official lab programs and tasks: Department of Computer Science and Engineering, Green University of Bangladesh. Code Commando and its art are original to this course.
