Object Oriented Programming Lab

Learn Java by building a game. Over ten chapters, Code Commando grows from a few variables into a full Swing game. Each chapter teaches one topic through the game, then the official lab tasks.

Start with Chapter 1CSE 201 theory notes
  • 1Lab IJava Syntax, Data Types & Control FlowMission 1 · The numbers behind the gameMeet Code Commando. Its health, ammo and score are variables; decisions and loops make it react.51 slides · 3 game tasks · 4 lab tasks
  • 2Lab IIClasses, Objects, Instances & MethodsMission 2 · Build the charactersOne class is the blueprint; every drone built from it keeps its own health.42 slides · 3 game tasks · 3 lab tasks
  • 3Lab IIIConstructors, Overloading & Reference PassingMission 3 · Arm upBuild weapons with different constructors, overload shoot(), and pass objects to methods.44 slides · 3 game tasks · 3 lab tasks
  • 4Lab IVInheritance, Polymorphism & OverridingMission 4 · Many enemies, one fightDrones, tanks and snipers are all enemies: shared code, their own attacks, one loop for the wave.45 slides · 3 game tasks · 3 lab tasks
  • 5Lab VAbstract Classes & InterfacesMission 5 · Rules every object followsAn abstract GameObject for everything on screen, and interfaces for abilities like Damageable.47 slides · 3 game tasks · 3 lab tasks
  • 6Lab VIException Handling & Custom ExceptionsMission 6 · When things go wrongWhen the gun runs dry or a level is missing, exceptions let the game recover and keep running.43 slides · 3 game tasks · 3 lab tasks
  • 7Lab VIIThread Creation & Thread StatesMission 7 · Everything at onceThe spawner, ammo refill and timer run at the same time: one thread each.41 slides · 3 game tasks · 3 lab tasks
  • 8Lab VIIISynchronization, Deadlock & Resource AllocationMission 8 · Sharing safelySoldiers share a scoreboard and supplies: avoid lost points and frozen soldiers.43 slides · 3 game tasks · 3 lab tasks
  • 9Lab IXGUI Components, Drawing, AWT & SwingMission 9 · Put the game on screenPut the game in a window: draw it with shapes and react to keys and buttons.47 slides · 3 game tasks · 3 lab tasks
  • 10Lab XAnimation with ThreadsMission 10 · Bring it to lifeThe finished game: a game loop, collisions and smooth animation, built from every chapter.57 slides · 3 game tasks · 3 lab tasks

Needs JDK 11+ and an IDE (NetBeans, Eclipse or IntelliJ IDEA). Official lab programs and tasks: Dept. of CSE, Green University of Bangladesh.
