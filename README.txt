Object Oriented Programming Lab (CSE 202) — interactive lab sessions, version 1

Open index.html in a browser. No build step is needed to view the site.

Structure:
  index.html      lab list
  labs/*.html     10 lab decks (←/→, F full screen, M slide list)
  js/lab.js       code viewer, run console, saved checklists, browser versions of the Swing programs
  js/lab-figs.js  lab diagrams (added to the figure registry in js/figs.js)
  css/lab.css     lab-specific styles
  Shared engine copied from the CSE 201 site: css/style.css, js/core, java, figs, quiz, page, slides, annotate, demos-*, art

The pages are generated by tools/build.py (kept next to this folder, not published).

Labs:
   1. Java Syntax, Data Types & Control Flow (44 slides)
   2. Classes, Objects, Instances & Methods (37 slides)
   3. Constructors, Overloading & Reference Passing (40 slides)
   4. Inheritance, Polymorphism & Overriding (35 slides)
   5. Abstract Classes & Interfaces (32 slides)
   6. Exception Handling & Custom Exceptions (36 slides)
   7. Thread Creation & Thread States (33 slides)
   8. Synchronization, Deadlock & Resource Allocation (35 slides)
   9. GUI Components, Drawing, AWT & Swing (38 slides)
  10. Animation with Threads (37 slides)
